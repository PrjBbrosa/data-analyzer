TraceLab — 应用图标方案 v2（精修）

四个差异化方向，按苹果应用图标规则做：squircle 圆角 + 多阶渐变 + 顶部高光 + 柔光层 + 圆滑笔触。 每个图标已加 Dock/Finder 风格的投影，渲染尺寸 256 / 128 / 64 / 32 / 16，亮深底各一遍。 挑一个编号告诉我，我做最后一轮微调 + 导出 .ico / .icns。

① TL Monogram — SF Pro 字形 + 暗藏波形

深蓝径向渐变底，"TL" 用 SF Pro Display 超粗字重 + 紧字距，下方一条细发光波形作品牌暗扣。

优点：识别速度最快、品牌印记最强；16×16 时去掉波形保留 "TL" 仍然清晰。 缺点：名字一改要重画。

③ Pulse Trace — 深空发光（最有动感）

深色径向渐变底（仿 Apple Logic Pro / Final Cut 那种深空感），一条信号尾迹 + 一个发光脉冲点。多层 radial gradient 模拟光晕。

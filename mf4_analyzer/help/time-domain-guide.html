02 · 勾通道出数据
01 · 02

在左侧勾通道就绘图

①

顶部点时域。

②

左侧通道列表勾选一个 / 多个通道 → 自动绘出曲线。

▸

取消勾选即移除该曲线；全选 / 全不 快速增减。WinWert 原始辅助线出现在所属文件下的 WinWert 原始记录分组，不参与全选。

▸

点眼睛只隐藏当前时域 View 的那条线，不改普通通道，也不改源文件。关闭文件或从当前 View 移除后，这些记录会从树里同步消失。公式警告里的「未生成」不等于整个 WWT 导入失败。右侧仍用绘图。

03 · 布局 + 游标
03

分屏看还是叠加看

▸

分屏：每条曲线各占一格（多坐标轴堆叠）。

▸

叠加：多条曲线叠在一张图（共享坐标）。

▸

单游标 / 双游标：在曲线上读数值、量差值。横坐标换成指定通道后，双游标按 X↑ / X↓ 分行统计，不再假装是时间区间。

分屏＝两格；叠加＝同一格两条线。

05 · 滤波看前后
05

滤掉杂讯，原始对滤波

①

右侧 时间范围 · 滤波 卡片里打开滤波开关。

②

选 低通 / 高通 / 带通 / 带阻，填截止频率，选陡峭程度，点 绘图。

▸

勾 显示原始 / 显示滤波后 做前后对比：滤波结果是虚线，叠在原曲线上。

▸

滤波不让波形错位、不改 FFT / 阶次结果；超出范围会自动提示。

06 · 叠加图怎么缩放
06

叠加模式 · 框选与滚轮

▸

框选放大：在叠加图上框一块，所有通道的纵向一起按这块放大——不用先选某条通道。

▸

裸滚轮＝整图上下平移；Shift+滚轮＝横向缩放时间轴。

▸

Shift + 滚轮＝缩放鼠标所在通道的纵向刻度。

▸

在坐标轴刻度区拖动＝只拖该通道的轴；在图中间拖＝整体平移。

框住的范围＝放大后看到的范围，每条通道各按自己的比例缩。

图卡顿时，可在右侧面板右下角打开 GPU 加速（时域图）（默认关）。

+ · 游标和 View 管理
+

读数、切换和关闭都不容易误触

①

游标显示设置可分别开关最小值点、最大值点，以及双游标的 Min / Max / Avg / 差值；− 收成 mini 后，完整读数仍在提示中。

②

View 色标关闭：当前 View 悬停色标会出现 ×；其他 View 先点一次只切换，移出再进入后才可关闭。

③

右侧 ⋯ 始终能管理全部 View；窄窗口会显示 »N。Windows/Linux 用 Ctrl+Tab 切 View；macOS 显示 Meta+Tab（⌃⇥）。图表复位是 Ctrl+R，Esc 每次只退出最内层临时状态。

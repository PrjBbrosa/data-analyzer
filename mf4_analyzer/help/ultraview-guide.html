总览

五个分析工作区之外的只读对照板：不计算、不改源 View，只摆已有预览。

01 · 它不是第六种算法
对照 · 不计算

五个工作区 + 一个只读总览

打开
在时域 / 频谱 / 时频 / 阶次 / 频响里，点各工作区 View 栏最右侧 UltraView，打开只读对照板。不重新计算、不补图、不改源 View。
加入
在源工作区里，View 标签右键 → 加入总览。也可以从总览左侧 View 库搜索后添加。没有现成预览时卡片就是「缺」，不会在后台悄悄跑分析。
打开原 View
选中后常驻「打开原 View」、过期才出现的「同步」、聚焦和更多；复制本卡图像、移到未放置、重新绑定、从总览移除在更多菜单和右键里。点「打开原 View」回到那个稳定身份的源工作区，而不是按显示名称猜测。
02 · 摆板
2 / 4 / 6

布局、托盘、拖放

布局

左右/上下双图、2×2、左主图+3 辅图、上主图+3 辅图、3×2 六宫格、3×3 九宫格、4×3 十二宫格。主图比例只作用于主图布局。九/十二图窗口不够时滚动，不把卡片压到不可读。

托盘

槽位满了再加入，多出来的卡片进底部托盘。托盘里的卡片仍属于这块板，可再放回空槽。

拖放

模板：拖到空槽是移动，拖到占用槽是交换。库或托盘拖到已有卡片上停留约 0.6 秒出现替换环，环内松手才替换。卡片右键「替换为…」走同一条意图。

View 库展开 / 概览
时域道路输入
频谱共振检查
阶次2–8 阶

五个分析类型。展开后直接加入或移出；概览先扫读再展开。搜索按名称与来源摘要；悬停看完整 tooltip，不用缩短名当身份。

03 · 四态
新 · 旧 · 缺 · 孤儿

卡片状态只描述预览，不触发计算

新 / 旧
新表示预览与当前展示一致。旧表示源 View 后来变了，总览仍显示上次抓到的图，等你回到源 View 再捕获。
缺
缺是合法状态：这个 View 还在，但进程里没有可用像素（例如刚重开项目）。不会自动补图。
孤儿
源 View 已被删掉。卡片提供重新绑定或从总览移除，不会假装还活着。
!

重开 .tlproj 会恢复板位和名称，但预览像素不随项目文件走。缺图保持「缺」，不会自动进入总览，也不会后台补算。

04 · 演示与导出
Esc · PNG

看清、复制、导出，不改数据

Esc

先关焦点放大，再取消替换，再退出演示，最后关掉弹出菜单。优先级固定，避免一层 Esc 连退两层。

演示

演示隐藏左侧 View 库和编辑控件，只留对照板。Esc 或再点演示退出。

导出

复制整板、复制单卡、导出 PNG（1× 或 2×）。卡图按 contain 放入格子，任何方向都不超过原图像素。

显示开关跟导出一致
标题可关，不留空带
来源可关，页脚高度为 0
板名工具栏内直接改

开关同时作用于屏幕与 PNG。项目会记住板名、布局和这两项显示。

05 · 边界
只读

总览不做的事

不计算
加入、筛选、演示、复制、导出、保存都不会调用分析入口。要新图，回到源 View 改完再捕获。
不猜测
身份是「分区 + 稳定 View id」。重名标签、缩短显示名、当前下标都不能当钥匙。
不发明
没有现成预览就显示「缺」。关闭全部文件时，若板是从项目恢复来的，不会被空会话误清掉。
06 · Board 与自由网格
多板 · 12 列

一块对照墙，可以按问题拆成多张 Board

Board

左上名称旁的 ▾ 打开弹层：点行切换，拖拽排序，行尾复制 / 删除。双击名称或 F2 重命名。顶栏 ＋ 新建空板。最多创建 20 个 Board；从项目读回时超过 20 只警告，不会丢板。

自由网格

新 Board 默认自由网格。12 列、最多 24 张卡。逻辑画布固定 1600 宽，与导出同口径，窗口拉伸或缩放不改变卡片长宽比。直接拖卡片移动，选中后拖边角改尺寸（Shift 保持比例）。选中条或右键「按原图比例」把卡片缩到贴合预览图宽高比（只缩不放）。移动不改任何卡的格数，缩放只改当前卡。拖动时完整 ghost 同时显示本卡和被推移卡的最终位置；无合法落点则拒绝并保持原布局，不弹确认框。空白处拖动画框框选多张，Shift+点加减选，组移动一次提交。Delete / Backspace 作用于全组。键盘仍可用 Option+方向键 微调、Option+Shift+方向键 改尺寸。卡片右键选尺寸预设。直接移动或调整后可使用 Ctrl+Z / Ctrl+Shift+Z 恢复或重做（编辑板名或搜索时仍走文本撤销）。

定位

右下角缩略图（minimap）只在自由网格且内容超出视口、出现真实滚动条时显示；模板、整板概览、演示或打开控制面板时隐藏。工具栏「概览」看整板，点一张卡回到阅读位置。当前布局模式用填充高亮，打开的面板用描边；关掉面板不会切换布局。都不改源 View、不重新计算。

画布缩放

新板默认适应视口，旁边仍留得出空格插入卡片。Ctrl+滚轮或触控板捏合以光标为锚缩放，范围 25%–300%。空格+拖或中键拖平移。工具栏 − / 百分比 / ＋ / 适应 / 100%。适应把已放置卡片居中放进浮层安全区。双击卡片把该卡铺满视口。≥60% 为完整卡片；40%–59% 为紧凑卡（隐藏页脚，保留预览、类型标签和信任状态）；低于 40% 为标题卡（预览高度为 0，并隐藏页脚与正文动作）。三种缩放都保留类型标签；用户标题不会被自动改名。整板概览仍保留，因为适应档位不能替代点卡片跳转。

UltraView（总览）
操作指南 · READ-ONLY BOARD

总览

五个分析工作区之外的只读对照板：不计算、不改源 View，只摆已有预览。

01 · 它不是第六种算法
对照 · 不计算

五个工作区 + 一个只读总览

打开
在时域 / 频谱 / 时频 / 阶次 / 频响里，点各工作区 View 栏最右侧 UltraView，打开只读对照板。不重新计算、不补图、不改源 View。
加入
在源工作区里，View 标签右键 → 加入总览。也可以从总览左侧 View 库搜索后添加。没有现成预览时卡片就是「缺」，不会在后台悄悄跑分析。
打开原 View
每张卡片右上角胶囊可直接点「打开原 View」、临时聚焦、按原图比例和从当前 Board 移除，不用先选中；移除不删除源 View，可用 Ctrl/Cmd+Z 恢复。过期才出现「同步」。更多菜单和右键只保留替换、移到未放置、复制本卡图像和尺寸预设。点「打开原 View」回到那个稳定身份的源工作区，而不是按显示名称猜测。左侧工具栏「一键更新源」可一次同步全部已变化预览，仍不重新计算。
02 · 摆板
2 / 4 / 6

布局、托盘、拖放

布局

左右/上下双图、2×2、左主图+3 辅图、上主图+3 辅图、3×2 六宫格、3×3 九宫格、4×3 十二宫格。主图比例只作用于主图布局。九/十二图窗口不够时滚动，不把卡片压到不可读。

托盘

槽位满了再加入，多出来的卡片进底部托盘。托盘里的卡片仍属于这块板，可再放回空槽。

拖放

模板：拖到空槽是移动，拖到占用槽是交换。库或托盘拖到已有卡片上停留约 0.6 秒出现替换环，环内松手才替换。卡片右键「替换为…」走同一条意图。

便签

自由网格左侧 Select / Sticky。N 或点 Sticky 后，点空白创建便签并立即编辑，拖框按起止尺寸创建。空内容退出不保存；有中文或其它文字后 Ctrl/Cmd+Enter 提交。便签是板上注释，不计算、不改源 View。文字、形状、画笔尚未提供。

五个分析类型。展开后直接加入或移出；概览先扫读再展开。搜索按名称与来源摘要；悬停看完整 tooltip，不用缩短名当身份。

03 · 四态
新 · 旧 · 缺 · 孤儿

卡片状态只描述预览，不触发计算

新 / 旧
新表示预览与当前展示一致。旧表示源 View 后来变了，总览仍显示上次抓到的图，等你回到源 View 再捕获。
缺
缺是合法状态：这个 View 还在，但进程里没有可用像素（例如刚重开项目）。不会自动补图。
孤儿
源 View 已被删掉。卡片提供重新绑定或从当前 Board 移除；移除不删除任何仍存在的源 View，不会假装还活着。
!

重开 .tlproj 会恢复板位和名称，但预览像素不随项目文件走。缺图保持「缺」，不会自动进入总览，也不会后台补算。

04 · 演示与导出
Esc · PNG

看清、复制、导出，不改数据

Esc

临时聚焦时 Esc 精确返回进入前视口。先关焦点放大，再取消替换，再退出演示，最后关掉弹出菜单。优先级固定，避免一层 Esc 连退两层。

演示

演示隐藏左侧 View 库和编辑控件，只留对照板。Esc 或再点演示退出。

导出

复制整板、复制单卡、导出 PNG（1× 或 2×）。自由网格按已放置内容裁切，与适应内容同一口径，不含空白底板。超出安全上限时提示实际尺寸，可改用 1× 或整理卡片，不拿画布墙限制布局。卡图按 contain 放入格子，任何方向都不超过原图像素。

显示开关标题 / 来源可导出
标题可关，不留空带
来源可关，页脚高度为 0
卡片操作常驻可关；悬停或键盘聚焦时显示
板名工具栏内直接改

标题/来源开关同时作用于屏幕与 PNG。项目会记住板名、布局和各 Board 的这两项显示；卡片操作常驻适用于当前工程的所有 Board，保存项目后保留。从 schema 3 打开的工程升到 schema 4 时，「卡片操作常驻」改为工程级偏好，Board 上的旧开关不再写回；从 schema 4 打开的工程升到 schema 5 时，旧 12 列坐标会自动转换为 24 列微格，屏幕上的卡片位置和尺寸保持不变；旧工程里的 viewport 相机会被忽略，打开总览仍走适应内容。

05 · 边界
只读

总览不做的事

不计算
加入、筛选、演示、复制、导出、保存都不会调用分析入口。要新图，回到源 View 改完再捕获。
不猜测
身份是「分区 + 稳定 View id」。重名标签、缩短显示名、当前下标都不能当钥匙。
不发明
没有现成预览就显示「缺」。关闭全部文件时，若板是从项目恢复来的，不会被空会话误清掉。
06 · Board 与自由网格
多板 · 弹性画布

一块对照板，可以按问题拆成多张 Board

Board

左上名称旁的 ▾ 打开弹层：点行切换，拖拽排序，行尾复制 / 删除。双击名称或 F2 重命名。顶栏 ＋ 新建空板。最多创建 20 个 Board；从项目读回时超过 20 只警告，不会丢板。

自由网格

新 Board 默认自由网格。12 列是基准网格和导出标尺；内部使用 24 列微格，因此不改变旧卡片的视觉尺寸，却能以半格精度贴合预览比例，减少上下或左右留白。工作区随内容扩展，四周可四向平移；左键按住空白框选，右键按住拖动画布；拖到边缘会自动平移并扩展画布。最多 24 张已放置、200 个 View。整数网格，卡片 1× 尺寸与导出同口径，窗口拉伸或缩放不改变卡片长宽比。导出 PNG 按已放置内容裁切。库或托盘拖入时，卡片按释放点附近插入；拖到已有卡片并停留出现替换环，才会替换。直接拖卡片移动，选中后拖边角改尺寸（Shift 保持比例）。右上角「按原图比例」按当前预览尺度收紧卡片外壳去贴图像宽高比，减少留白，不整板重选尺寸。移动不改任何卡的格数，缩放只改当前卡。拖动时完整 ghost 同时显示本卡和被推移卡的最终位置；无合法落点则拒绝并说明原因和下一步，不弹确认框。空白处拖动画框框选多张，Shift+点加减选，组移动一次提交。Delete / Backspace 从当前 Board 移除全组，不删除源 View。键盘仍可用 Option+方向键 微调、Option+Shift+方向键 改尺寸。卡片右键选尺寸预设。直接移动、调整或移除后可使用 Ctrl/Cmd+Z / Ctrl+Shift+Z 恢复或重做（编辑板名或搜索时仍走文本撤销）。画布空白处右击可适应内容、100%、概览、自动排版（保留每张尺寸，可撤销）、复制图片、导出 PNG；自动排版不是整理空行。

定位

右下角缩略图（minimap）只在自由网格且内容超出视口、出现真实滚动条时显示；模板、整板概览、演示或打开控制面板时隐藏。工具栏「概览」看整板，点一张卡回到阅读位置。当前布局模式用填充高亮，打开的面板用描边；关掉面板不会切换布局。都不改源 View、不重新计算。

画布缩放

每次打开 UltraView 或切换 Board 都自动适应已放置内容（空 Board 按两卡工作框），不恢复上次平移或缩放。Ctrl+滚轮或触控板捏合以光标为锚缩放，范围 25%–300%。左键按住空白框选，右键按住拖动画布；空格+拖、中键拖或手掌也可四向平移；拖到边缘自动平移并扩展画布。工具栏 − / 百分比 / ＋ / 适应 / 100%。适应内容把已放置卡片居中填满点阵画布，最高 300%；100% 保持当前视口中心。双击卡片临时聚焦最高 300%，Esc 返回。≥60% 为完整卡片；40%–59% 为紧凑卡（隐藏页脚，保留预览、类型标签和信任状态）；低于 40% 为标题卡（预览高度为 0，并隐藏页脚与正文动作）。三种缩放都保留类型标签；用户标题不会被自动改名。整板概览仍保留，因为适应档位不能替代点卡片跳转。

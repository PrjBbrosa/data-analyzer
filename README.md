# TraceLab / MF4 Data Analyzer

TraceLab 是用于工程测量数据浏览、时域/频域/阶次分析、批处理和采集回放的 PyQt5 桌面工具。

## 8.2.0 当前版本

- 稳定性封口：WinWert 原始记录的眼睛开关严格跟随当前聚焦的时域 View；切换分屏或点击旧行不会影响另一 View。
- UltraView 拖动结束后的页面更新更稳健；智能排版、紧凑排列、按原图比例和适应内容保持各自职责，保存重开后不发生额外重排。

- 新增 UltraView 只读总览工作区：可把时域、频谱、时频、频响和阶次 View 组织到多个 Board 中对照，不重新计算、不修改源 View。
- UltraView 支持模板布局与 12 列自由网格，可直接拖动、缩放、框选和成组移动卡片，并提供画布缩放、平移、适应视图、minimap、逐 Board 撤销/重做和 PNG 导出。
- UltraView 的 Board、卡片引用、布局和视口随工程保存；入口在已有卡片时显示状态提示，缺失或过期预览保持可见且不会静默补算。
- 工程保存改为原子替换；重新打开工程会恢复并重新计算所有带来源的分析 View，而不只处理当前标签。
- 大型 BLF / ASC 文件打开不再先铺开整份高密度公共表，时域密集曲线的缩放与光栅缓存路径进一步稳定。

- 每个分析 View 拥有独立的文件范围：新建 View 默认为空，切换 View 各自恢复，复制 View 才继承整份配置。
- 文件区链接按钮升级为“文件范围跟随”菜单：新文件加入当前 View、新建 View 继承文件范围、切换分析时填充空 View，三项可自由组合；全部关闭即不跟随。
- 行为变化：开启“新文件加入当前 View”后，在分析页加载文件会加入当前分析 View，不再写入后台的时域 View；时域页行为保持不变。
- 批处理表格支持拖拽导入文件，BLF+DBC 磁盘导入复用主窗口的配对流程；筛选字段接受中文逗号分隔，多来源文件组关闭提示合并为一条。

- 新增独立的频响（FRF）系统辨识：按输入/输出配对计算 H1 / H2，统一查看幅值、相位和相干度；也可在批处理中对多组文件批量出图、出表。
- FRF 的单/双游标、频率刻度和三面板坐标对齐进一步收口；工具栏现在和时域一样支持标注、清除标注，标注在对数频率轴上仍显示真实 Hz 数值。
- 分析参数面与批处理控件按统一视觉和布局规则整理，常用操作更容易识别；当前 View 中的文件可直接移除，分析信号选择范围保持同步。

- HEAD HDF 通道名改为读取文件中的完整扩展名称；通道树对长名称采用中间省略，悬停仍可查看全名。
- FFT、时频、频响和阶次分析的信号选择，以及时域 X 轴取景范围，都会跟随当前 View 中实际挂载的数据源。
- 时域高变化曲线统一按屏幕实际“墨水量”控制抗锯齿与光栅缓存，避免 Y 自适应后出现数秒甚至更久的冻结帧。
- 下拉框右侧圆角不再被内部按钮的方形背景覆盖，统一为 7px 圆角。
- 阶次谱图的时间轴改为等距支撑网格：分析点落在设定的时间分辨率整数倍上，批处理切片位置可精确命中（如 10 秒切片切在 10.000 秒）。
- 阶次谱图的时间轴只显示实际算出结果的区间，两端不再画出无分析点的范围，坐标轴与数据一致。
- 批处理代表图预览会显示切片位置的夹取与合并提示，不再静默吞掉渲染层警告。
- 阶次面板时间分辨率的说明更正：它只决定时间轴疏密，不影响阶次分辨率。
- 批处理阶次分析可使用其他采样率数据源中唯一匹配的 RPM 通道，并按时间轴完成配对，避免噪音与转速采样率不同而无法计算。
- 批处理时频图和阶次图的切片位置增加半透明红色高亮带，同时保留与下方曲线对应的彩色中心线，导出图更容易定位。
- 批处理面板按屏幕可用高度自适应，笔记本上底部的运行 / 预览 / 关闭不会再被裁掉；代表图预览窗口同样自适应。
- 批处理面板顶部两行收紧，中间的分析栏在 1366×768 屏幕上可完整显示。
- 批处理的运行 / 预览 / 中断以及预览窗口内的按钮改用全局统一的主次配色。
- 批处理文件与通道选择流程更清晰，图像导出选项和渲染结果校验更完整。
- 时域自定义横轴按数据源独立解析；不兼容来源会保留明确诊断，不再影响其他可用来源。
- 精密触控板的 Ctrl / Shift 缩放在时域、FFT、FFT 预览、时频图、阶次和切片视图中统一支持双向缩放；叠加模式下 Shift 缩放 Y 轴可以正常放大和缩小。
- 时域交互的粗刷新间隔限制为 100 ms，密集叠加曲线会根据绘制压力自动控制抗锯齿，拖动与缩放更稳定。
- 通道配置管理器升级为草稿编辑：可预览当前 View 的通道匹配和单位，支持新建、复制、重命名、单项/批量删除与撤销；只有“保存更改”才写入本机配置。
- 通道配置可导入/导出 JSON；同名配置导入时可选择保留、替换或跳过，旧配置仍可继续读取。
- 导入 `.wwt`：读取原生 WinWert 测量文件，保留时间轴、单位和缩放信息。
- 导入 `.zfd`：读取 ZFGE2 / TestRunPRO 通道块；文件未提供可靠采样间隔时会明确标记估算采样率。
- 导入 `.mat`：支持 MATLAB v4-v7，并通过 HDF5 兼容 v7.3；识别显式时间变量，不猜测工程单位。
- Windows 同时提供完整包 `TraceLab8.2.0` 与仅分析功能的轻量包 `TraceLabAnalyzer8.2.0`。

## 数据导入约束

- 分隔型 ASCII 必须带可识别的时间列；固定宽度 ASCII 必须带已验证的采样间隔。软件不会猜测采样率。
- TDMS 仅导入带有效波形时基的非空数值通道；`.tdms_index` 是配套索引，不是可打开的数据文件。
- WWT 使用文件内 `Zeit` 时基；ZFD 在时基缺失时会显示估算状态；MAT 只使用可识别的显式时间变量，单位留空而不臆测。
- 批处理与图形界面使用同一套 ASCII/TDMS 导入规则。

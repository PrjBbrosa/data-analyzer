交互逻辑（你提的两个问题的答案）

  • 拖动拖分割线 = 任意比例调整上下两图。可以拖到对半甚至更极端，但两边各留最小高度（拖不到 0）。"只看一张图"由三角负责，拖动不把谁拖没 —— 折叠入口只有一个，心智干净。
  • 折叠小三角 = 完全折叠 / 恢复下图。折叠时下图 height→0、上图占满，三角转 90° 高亮。
  • 恢复折叠后恢复 → 回到「你上次拖的比例」（记住），不是固定默认。三角=临时最大化主图的开关，恢复时把你之前的布局原样还回来（没拖过就是默认 60/40）。同 IDE 面板折叠再展开的习惯。
  • 重置双击分割线 = 回默认比例（60/40）。给一个"拖乱了想还原"的明确入口。
  • 边界拖动时只在「两图都显示」时可用；折叠状态下没有分割线可拖，只有三角生效。窗口 resize 时按记住的比例重算，下图不会突然变形。

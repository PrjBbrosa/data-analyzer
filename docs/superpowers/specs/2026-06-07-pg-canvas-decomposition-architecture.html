这 21 个核心字段的"广播式"耦合是 结构必然，不是设计缺陷：图表是单一统一渲染目标，overlay 光标/批注/网格必须与数据 同帧同步。强行外部化只会用掉帧换"解耦"。

_channel_name_for_handle 在行 2224 与 3279 各定义一次，两份逻辑相同、第二个静默覆盖第一个。当前无害，但属"同名方法重复定义"腐化模式，Phase 0 顺手清除。
对外契约极小 → 安全边界好

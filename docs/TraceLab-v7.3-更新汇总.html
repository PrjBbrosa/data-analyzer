1

新增能力

6.0 说明书完全没有的
01

项目工程 .tlproj

✓ 已接入

把「打开了哪些文件 + 勾了哪些通道 + 视图布局 + 各分析参数」整体存成一个工程，下次一键还原；只记文件位置、体积小、便于分享。

工具栏因此改版：原「添加文件 / 导出」→ 「打开 / 保存项目」；「导出」挪进了「编辑通道」。

02

多视图 / 分屏对比

✓ 已接入

图表区可并排分屏，缩放/平移联动；点某栏聚焦后操作只作用于它；FFT / 阶次 / 时频可开「对比」叠加；时频热图并排可锁定色阶；Alt+1..6 快速切视图；布局随工程保存。

03

打开 HEAD 声学 .hdf

✓ 已接入

能直接打开 HEAD .hdf：有专门的导入对话框，可选采样率组、按采样率/物理量分组、应用标定。打开后照常做时域、FFT 等分析。

⚠️ A计权 现已接入 FFT/时频/阶次（见卡片 10，可写）；响度 / 倍频程 / 心理声学等其余声学分析算法虽写了但仍没接到界面，别写。

04

信号类型预设

✓ 已接入

参数面板里可选信号类型预设（扭矩 / 振动 / 启停），按通道自动推荐合适预设，参数旁有说明气泡。

❓ 目前只确认这 3 种接入了面板，其余待你确认（见文末）。

10

音视频导入 + A 计权

✓ 已接入

「打开」可选音视频文件（.mp4 .mov .mkv .m4v / .mp3 .m4a .aac .wav .flac）：自动取出声音轨道作为通道，照常做时域 / FFT 等分析。

FFT / 时频 / 阶次 参数面板新增「频率加权」下拉（None / A）：A 计权按 IEC 61672 对各频段加权。

⚠️ A 计权是相对加权频谱，非绝对 dB SPL；说明书按「分析声音更贴近人耳听感」写即可，别写成声压级标定。

2

已有功能更好用

05

FFT 框选 + 「最大」按钮

✓ 已接入

FFT 上方时间预览区左键一拖即可圈定分析时段；时间范围新增「最大」按钮，一键设为整段数据。

06

折叠抽屉 + 游标差值

✓ 已接入

时间预览 / 切片面板可拖动折叠收起；游标显示每条曲线相对主曲线的差值。

07

导出更细

✓ 已接入

在「编辑通道」里：勾选要导的通道 → 导出 Excel；可选仅导出可见范围、是否含时间列。

3

更快 & 更好看

08

渲染换代 + GPU 开关

✓ 已接入

分析图表换用 pyqtgraph 引擎，重计算移出界面线程、可随时取消，大数据更顺滑；新增 GPU 渲染开关、高清（HiDPI）导出。

09

全新外观

✓ 已接入

雪色界面（浮起圆角面板）；底部操作提示条；工具栏 BOSCH logo；状态栏更新图标（点击跳发布页）。

M0.3 已记录的产品决定

  1. ACCEPTED — rail 保留全部：Library / Free Grid / Layout / Filter / Select / Sticky / Text / Shape / Connector / Draw / Unplaced / Sync 都留在左轨。作者工具插在 Filter 与 Unplaced 之间。
  2. ACCEPTED — 左上保持现状：Board Island 仍是板名 + 切换 + 新建 Board。不把 View Library 改成 + View。
  3. ACCEPTED — selection toolbar：40px 单行，Signal Spine，Delete 进 More，拖动中隐藏。
  4. ACCEPTED — Shape / Draw flyout：图形网格 + 真实 preset，不用平台 QMenu。Connector 独立。
  5. ACCEPTED — 不做 dark：作者 chrome 只按 light 设计和验收。不新增 uvx dark 变体。
  6. ACCEPTED — compact：800×560 Global 收进 ⋯，toolbar 不换行，rail 不截断、不改成横向条。

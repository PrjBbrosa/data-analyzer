位置与颜色各司其职

Pin 用 P1 / P2 编号匹配；通道保留青色与紫色。未选中线用清晰蓝灰虚线，选中线用蓝色实线，不把波形颜色占作 Pin 配色。

统一行为约定

Pin 固定数据位置，不固定屏幕像素。缩放后仍保留记录，视野外明确标注；删除不重排编号。此页仅演示当前 View，不模拟项目保存。

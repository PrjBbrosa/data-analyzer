最终密度顺序

  1. Roomy：anchor + 所有完整 View 名称。
  2. Compact：anchor 保持完整；当前 View 仍显示完整名；其余显示彩点 + 顺序号，完整名在 tooltip。
  3. Overflow：当前 View 与可容纳的相邻 View 留在条上，其他项进 »N；菜单始终显示完整名称与当前勾选。

实现边界

  1. 每次 resize、切换 View、重命名、增删 View、比较窗格显隐后重新测量。
  2. 不得通过隐藏当前 tab 让 Qt 自动换选；当前 View 必须先被保留，再按邻近顺序收纳其它 tab。
  3. anchor 是展示层的 SectionContext，不写入 ViewState，也不改现有 View 名称或颜色持久化。

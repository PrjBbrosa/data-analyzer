交互裁决

工具轨不承担设置面板职责。它只选择“下一次在画布上做什么”，选中对象的格式在画布上方出现。

01
三段而非一列混放BOARD 保留已有入口，CREATE 专给创作，底部保留镜头与撤销。
02
一次性与连续性清楚便签、文字、形状放置一次即回选择；画笔保持，直到 Esc。
03
复杂度停在边界折线箭头不做自动避障；擦除整笔；文字工具条不伪造字符级富文本。
Miro 借鉴 / UltraView 取舍16 色便签、轻量 Stack、形状清单、三档画笔与选中后浮动文字条均保留。AI Generate、评论、协作、自动连线避障和压感不进入首发。

现状问题

  • 语义「自动」用复选框，看起来像可多选，实际是区间模式。
  • 节奏三个勾选横向挤在一起，和上方摘要条、切片/滤波卡不统一。
  • 上下文自定义 X 长通道名纯文本，窄栏易读性差。

方案 A · 推荐

  • 一致区间改 SegmentedChoice（自动 / 手动），与幅值单位、切片维度同族。
  • 手动范围点「手动」后，在分段正下方展开「最小 — 最大 + 单位」双 spin（点预览里的「手动」可看）。
  • 为何不并排288px 栏里分段已占满字段列；并排放 spin 会挤成现状那种碎行。
  • 可扫指标改成可点 chip；X 上下文收入字段条。

方案 B · 最小改动

  • 只把区间换成分段；统计项目仍用复选框。
  • 适合想先修「自动像勾选」这个最大违和，不动指标交互习惯。
  • 上下文略加强分隔，但仍偏朴素。

方案 C · 工具条感

  • 区间、指标都改成等宽分段块；标签上移成小节 caption。
  • 三项指标并排更整齐，窄栏下仍稳定。
  • 比 A 更“硬”，实现仍是 SegmentedChoice / 三按钮互不互斥组。

方案 D · 上下文优先

  • 把自定义 X 提到设置区第一行字段条，摘要里只留短状态。
  • 适合通道名很长、用户常要确认「统计绑在哪个 X」的场景。
  • 文案更短（区间/项目），信息密度略高。

建议

  • 产品默认走 A：和刚落地的分段控件一致，视觉提升最明显。
  • 若只想快修语义违和，可先上 B，指标 chip 留二期。
  • 手动区间仍用现有双 spin（最小—最大 + 单位），各方案切换到「手动」时共用同一套。

推荐规则：单个 View 点击 × 后不弹窗，底部短时提供“撤销”；“关闭其他 / 关闭全部”只弹一次确认。关闭的是主 View 或对比 View 时，确认文案明确提示“当前对比会结束”。最后保留一个已重置的空白 View，符合现有 ViewManager 不允许零 View 的状态约束。

TimeDomain 右键菜单重设计方案

目标不是把 pyqtgraph 的原生菜单翻译完就交给用户，而是把“看图时真正会用”的动作放在前面，把高级/危险/少用的原生项收纳起来，并彻底避免说明气泡挡住二级菜单。

推荐方向：方案 A · 常用优先

最适合 TraceLab 日常看曲线：一级菜单少、二级菜单清楚、说明固定在菜单底部，不再浮在最前面。高级 pyqtgraph 功能保留但降级到三级“高级显示”。

设计原则

说明不遮挡禁用菜单动作 tooltip，改成底部 inline help 或右侧详情栏。
原生高级项降级Transform、Average、Alpha、Points 不是主流程，统一收进高级层。
圆角真的圆PyQt 里必须让 popup 外层透明，或改成自绘 popup，否则 QMenu 窗口外壳仍会是方的。
层级不超过三层一级做导航，二级做设置，三级只放专业/低频功能。

方案 A · 常用优先推荐

一级菜单只放用户能理解的动作。X/Y 轴进入二级设置面板，绘图高级项放三级 drawer。解释文案固定在底部，不使用悬浮 tooltip。

优点最接近现有浅色系统，学习成本低。
代价需要用自定义菜单结构替代部分 pyqtgraph 原生菜单。
适用日常分析、调图、导图。

方案 B · 分组菜单

保留传统右键菜单形态，但把项目分组为“视图 / 坐标轴 / 显示 / 导出”。二级子菜单仍是菜单，不展开复杂表单。

优点实现成本最低，可以从现有 QMenu 继续演进。
代价坐标轴数值输入仍然拥挤，不适合复杂设置。
适用短期止血、替换原生菜单。

方案 C · 命令面板式

右键后不是多级菜单，而是一个小型命令面板：顶部搜索/过滤，下面是常用动作和高级折叠组。适合后续功能变多，但和传统菜单差异更大。

优点解释空间充足，不会出现层级遮挡。
代价不是标准 QMenu，交互习惯需要适应。
适用长期可扩展版本。

功能取舍建议

功能建议原因放置层级
查看全部保留用户缩放迷路时最高频，和 toolbar Home 一致。一级
X/Y 轴范围、自动缩放、鼠标交互保留调图核心功能，但原生表单太拥挤，应重排为二级面板。二级
鼠标模式保留但改名“3 button / 1 button”看不懂；改成“平移模式 / 框选缩放模式”。一级或二级
网格、导出保留可理解、可见效果明确；导出也可直接走现有 toolbar 保存。一级
Transform / FFT / 去均值 / dy/dx收起会改变用户对原始时域数据的理解，放一级容易误触。三级高级
Average / Alpha / Points收起低频显示调试功能，不应挤占主菜单空间。三级高级
pyqtgraph 原生 Export Dialog可保留但降级功能多但界面不是本应用风格；主路径建议用 toolbar 保存/复制。高级或导出二级
悬浮 tooltip不要会挡住子菜单和设置面板；改成 inline help。删除
实现备注： PyQt 如果继续用原生 QMenu，仅靠 border-radius 往往会留下方形窗口外壳。短期可尝试 WA_TranslucentBackground + 透明外层背景 + 禁用菜单 tooltip；更稳的方向是把 TimeDomain 右键菜单改成自绘 QFrame/QWidget popup，这样二级/三级层、圆角、阴影和 inline help 都可控。最终落地前需要真实 Qt 截图验证圆角外框、间距、字体和层级遮挡。

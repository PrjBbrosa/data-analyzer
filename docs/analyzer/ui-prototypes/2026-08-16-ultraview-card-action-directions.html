UltraView / Icon & action hierarchy study

不要让“更多”再承担已经可见的动作。

目标用户是在大画布上对比多个 View 的工程师。图标应像精密仪器的刻度：统一、锐利、动作含义单一；危险动作不用藏起来，也不该在两个入口重复出现。

已确认的根因当前卡片同时有 40px 选中浮岛与 24px 卡头工具条，两套都含“打开 / 放大 / 适应 / 更多”；卡头 22px 按钮配 14px 图标，而浮岛是 30px 按钮。删除一边是“方框减号”、另一边藏在 …，Board 复制则误用了图片复制符号。
推荐 · 单一选中浮岛

方案 A：精确四键

只保留“选中卡片”上方的一个 40px 浮岛。高频动作直达，删除有独立危险样式；… 仅保留不常用且不重复的动作。

View 2 · 扭矩对比

关键：… 内不再出现“删除 / 打开 / 放大”。

  • 40px 高、30px 命中区、16px glyph。所有可见工具都同一节拍。
  • 删除直接可见且独占红色。点击前提示“仅从当前 Board 移除”。
  • 未选中卡不露工具；选中后浮岛靠近卡片，符合 Miro 的上下文操作感。
紧凑保守

方案 B：卡头四键

保留每张卡头的即时操作，不使用额外浮岛。适合用户总在小卡上连续切换，但视觉密度较高。

View 2 · 扭矩对比

代价：即使没有选中卡片，卡头仍有一排高对比控件。

  • 固定 28px 命中区、14px glyph。不再混用 22/30px。
  • 适应尺寸进入更多菜单。腾出空间给标题，模板布局下也避免一个禁用图标。
  • 删除始终最右且红色；更多菜单绝不重复删除。
极简画布

方案 C：悬停显现

默认只看图，悬停或键盘聚焦后从卡头滑入操作条。视觉最安静，但首次发现成本最高。

View 2 · 扭矩对比

风险：需要有首用提示，且不可把“删除”也完全藏在右键菜单。

  • 默认隐藏，hover/focus 才显现。不再使用 …，右键仍给完整菜单。
  • 必须保留键盘焦点、tooltip 与快捷键；不可把悬停当作唯一入口。
  • 适合“看图优先”的演示模式，不适合高频编辑布局。

图标语义合同：不用“图片”代表“复制 Board”

建议全部使用项目已经安装的 qtawesome / Font Awesome 5，以矢量 QIcon 在当前 DPR 重绘；不再用每个动作各自的 QPainter 小图形。

Board 行的修正

“复制 Board”复制的是布局与 View 引用，不是输出图片；应使用 clone。图片图标只保留给“复制本卡图像”。

全局对比

删除 Board 仍需确认；卡片移除不删源 View，提示文案必须明确这层边界。

我推荐 A 的原因

“Portal”把特殊性集中在 2×2 看板口：这里是从单个 View 进入全局对照的门，而不是另一个颜色不同的普通按钮。

不会侵蚀现有合同

四种都保留右端 Dock、28px rail、高密度操作区和窄态图标退化；比较 / 取消组合出现时，入口不移动。

刻意没有加的东西

没有卡片数 badge、常驻弹窗、持续动效或大面积渐变底色。它们会把全局“查看”误导成待处理通知。

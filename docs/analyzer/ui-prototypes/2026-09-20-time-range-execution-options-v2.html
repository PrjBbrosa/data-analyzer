共同规则与实施边界

同一条绘图链。A/B 的全时段命令先将输入写为来源完整起止，再执行与主按钮相同的绘图；不会保留局部草稿。B 的菜单不改变主按钮默认动作，也不把上次全时段动作变成粘滞模式。

源范围不是固定从 0 开始。本演示采用 0–60 s 合成数据。产品应取当前 View 所选来源的真实时域边界，不包含无关已加载文件；多来源保留各自有效范围和既有缺失数据处理，不伪造填补。

待绘参数与已绘结果。输入变化时显示“待绘图”，结果保持上次成功状态；成功绘图后两者一致，显示“已应用”。失败时不能假报已应用，也不能为了兜底静默绘制全时段。这个区分是执行前后的反馈，不是隐藏的范围启用开关。

无效值。空值、非数字、开始 ≥ 结束、超出来源范围，都会阻止按输入绘图。显式全时段操作可以用有效边界替换无效输入，再绘图；无数据时禁用全部执行入口。Enter 与主绘图一致。

D 仅用于比较操作成本。它在停止输入 800ms 后自动绘图，两个字段之间的停顿可能引发中间范围计算。长记录、多通道或昂贵滤波下不倾向使用；若采用还需取消/合并计算及旧结果拒收，原型没有假装验证这些运行时能力。

视图与参数分离。普通缩放/平移只改变视窗；“取当前视窗”才明确把时域视窗写入参数。程序恢复和来源回填不是用户编辑，不能自动绘图。Custom-X 不得把工程单位当成秒，FFT/FRF/阶次及统计/导出的范围语义需在选型后单独明确。

没有重复实现产品。本页只模拟一个时域 View。方案按钮、试用工具、300px 预览、无数据开关及执行计数是验证辅助，不建议加入产品界面。保留现有白底蓝色、紧凑 Inspector 视觉。

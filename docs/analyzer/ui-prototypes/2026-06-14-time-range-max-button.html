时间范围「最大」按钮 — 放置方案对比

2026-06-14 · 一键把「开始 / 结束」填满整段数据。点击任意卡片里的「最大」按钮看效果。

逻辑（复用现成的上下界，零额外计算）

  • 每次加载 / 激活 / 重建文件时，main_window 已经调用 set_range_limits(0, max_t)，其中 max_t = max(各文件 time_array[-1])。所以 spinbox 的 minimum() / maximum() 就是整段数据的上下界。
  • 「最大」点击 → set_range_values(spin_start.minimum(), spin_end.maximum()) → 即 [0, 全程时长]。直接复用已有方法，不新增数据通路。
  • 同一个范围组在 时域 / FFT / FFT vs Time / 阶次 四个模式间复用 → 按钮只加一处，四个模式同时生效。
  • 待定的小决策（见底部问题）：点「最大」后是否顺带勾上「使用选定时间范围」； 以及文案用「最大 / 全程 / 全时段」。

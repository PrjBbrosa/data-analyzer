A · 基线

同名同色

切换时底部零变化。空间记忆失效，最容易把「另一个 section 的 View 1」当成同一个。

B · 首选

安静归属

不改命名契约，只让 View 条属于当前 mode。克制、可落地、和现有双击重命名不冲突。

C · 长期

内容命名

辨识度最高。空 View 仍叫 View 1；有信号后变成内容名。实现与边界情况更多。

D · 备选

淡色洗底

地点感更强，但容易和 View 色点抢注意力。适合作为 B 的加强版，不宜单独做得很艳。

未单独做「频谱 View 1」前缀方案：作为 Mac 工程软件观感偏实验室。若需要对照，可在 B 落地后用文案实验再比。 本页只做视觉直觉，不代表最终实现细节。

4. Compact Chips

最轻、现代感强；但不太像“工作表标签”，拖动排序和右键菜单的可发现性弱一点。

我的建议是结构选 A，样式选 2。实现上把 toolbar、ViewTabBar、hint bar 都提升到 ChartStack 的时域页面级别，splitter 内只放两个 canvas pane；这样并排时左右图面高度一致，标签也不会因为挂在左侧 card 里导致右侧短一截。

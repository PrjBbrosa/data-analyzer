状态与操作的边界

“收起”不是删除；“精简”不是收起；“取消固定”不是删除。hover 使用小幅边框增强；键盘 focus 有独立外环。拖动时保持选中强调，不因指针离开按钮而变浅。

原型说明

可试开合、显示切换、删除 / 撤销、取消固定、重新固定及拖动。撤销是演示恢复入口，是否加入产品需另行决定。浏览器效果不等同 Qt 原生验收。

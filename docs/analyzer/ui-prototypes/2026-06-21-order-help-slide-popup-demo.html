TraceLab Guide

阶次分析什么时候用

当转速在变，普通 FFT 里的频率线会跟着漂。阶次分析把信号按转角重采样，直接看 1 阶、2 阶、齿轮啮合阶次等“跟转速同步”的成分。

6 页 · 面板内帮助
1

适合

启动、加速、滑行、换挡、变速扫频，或任何需要把频率换算成阶次的工况。

2

需要

一个待分析信号，加一个同时间轴的转速信号。转速越连续，阶次线越稳定。

3

不适合

没有 RPM、RPM 长时间为 0、或只关心固定频率设备噪声时，优先看 FFT / FFT vs Time。

4

先看

先用全时段和推荐预设跑一张图，再围绕异常时间段、目标阶次和色阶做精调。

Input Check

先把信号和转速配对

Order 图的质量主要由输入决定：信号、RPM、时间范围三件事先确认。

信号选择振动、扭矩、压力等要分析的通道；它决定色阶里的幅值。
转速选择同一段时间里的 RPM 通道；RPM 系数用于修正单位或脉冲比例。
Fs采样率用于缓存、显示和参数身份；通常来自文件，手动改动要谨慎。
分析时间默认全时段。只看启动、急加速、制动片段时，再启用选定时间范围。
信号和 RPM 必须是同一工况
RPM 长时间为 0 时不能解析阶次
Parameters

谱参数分别控制什么

先保留“自动 FFT 点数”，主要调最大阶次、阶次分辨率和时间分辨率。

最大阶次
决定 Y 轴计算到几阶。只关心低阶问题就别开太大；高阶覆盖越宽，计算和显示越重。
阶次分辨率
数值越小，阶次轴越细；但需要更多转数和更大的窗口，否则细节不一定可靠。
时间分辨率
数值越小，时间帧越密，瞬态更清楚；代价是噪声更明显、计算量更高。
FFT 点数
自动会按每转样本、阶次分辨率和可用转数取值。手动指定过大时，短片段可能不够一帧。
频率加权
A 计权会按每帧 RPM 把阶次换算成 Hz 后加权；适合声学感知，不等于原始机械幅值。
dB 参考
只影响 dB 显示换算的参考值。不同项目要可比时，保持同一参考值和同一加权方式。
Presets

三个预设怎么选

预设不是最终答案，是快速起点。系统会根据通道单位给推荐标记，你也可以手动切换。

频率优先

扭矩 / 压力 / 稳态量

阶次分辨率更细，时间帧相对粗。适合找稳定阶次、窄带峰值和幅值对比。

默认：≤20 阶 · 0.05 阶 · 0.10 s · 自动 FFT · 256 点/转

均衡

振动通用诊断

时间和阶次折中，覆盖阶次更高。适合大多数加速度、速度、位移类通道。

默认：≤50 阶 · 0.10 阶 · 0.05 s · 自动 FFT · 512 点/转

时间优先

启停 / 冲击 / 瞬态

时间帧最密，阶次分辨率相对粗。适合先定位异常出现在什么时刻。

默认：≤30 阶 · 0.25 阶 · 0.02 s · 自动 FFT · 256 点/转
Axes & Levels

坐标轴和色阶怎么调

坐标轴设置只影响“怎么看”，不会改变已经算出来的阶次矩阵；需要新参数时再点计算。

X

时间

自动显示当前计算覆盖的时间。手动范围用于放大某段工况，不会重新计算。

Y

阶次

自动显示 0 到最大阶次。只看目标阶次时手动缩窄，例如 0-10 阶。

Z

色阶

拖 colorbar 或输入范围只改变亮暗映射。过暗就抬低限，过曝就降高限。

Read & Diagnose

图出来以后怎么判断

先看整张热图，再点异常位置取下方切片。不要只盯最高峰，连续性和工况位置同样重要。

亮的水平线

通常是跟转速同步的阶次成分。1 阶、2 阶、半阶、齿轮啮合阶次可以优先标注。

只在某段时间变亮

多半和工况事件相关，例如启动、换挡、共振穿越。用时间范围或切片进一步确认。

大片空白或断裂

先检查 RPM 是否掉零、时间范围是否太短、手动 FFT 点数是否超过可用转数。

幅值不好比较

确认 dB / Linear、dB 参考、A 计权和色阶范围一致。显示口径不同，颜色不能直接横比。

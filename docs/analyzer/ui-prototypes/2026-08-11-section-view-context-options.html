Section 切换后，View 条该怎样告诉人「我在这里」？

三张原型共享相同的工作区和相同的 View 1，只测试不同的定位语言。点击各卡右上角的 section 图标，以及底部 View 标签，观察它们是否仍能在高频切换时保住方位感。

不改 View 名称与持久化，只改变展示层
Option A · Quiet anchor

安静的当前位置锚点

View 条属于当前 section；用“图标 + 名称 + 细 accent”交代位置。View 继续只表达本 section 内的工作台编号。

推荐：信息够用，侵入最小

Option B · Instrument plate

Option C · Path language

把位置写成一条短路径

用文字而非色块表达层级：分析 / 频谱 / View。最不依赖色觉，但比 A 多一层阅读，适合把“View”明确理解成工作区的人。

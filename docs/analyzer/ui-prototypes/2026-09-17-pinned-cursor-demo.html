移到目标位置，按 P 固定。轴下方 P1 / P2 对应各面板；拖标题移动，− 收起，× 关闭。P1、P2 已固定；右上角是当前活动面板。

移到位置，按 P 固定

固定：鼠标停在目标位置，直接按 P，当前面板和读数立即固定；无需先单击，也无需移到面板。继续移动鼠标，查看下一处，再按 P。

定位：轴下方常驻 P1 / P2 标记，淡虚线指示取值位置。悬停标记或面板，两者一起高亮；点击标记将对应面板置顶。

每张独立：拖标题移动；− 收起为紧凑读数；+ 展开；× 关闭这一张。

取消固定：点击蓝色图钉，这张面板在原地恢复为活动游标，可调整后重新固定。其他固定面板不受影响。

双游标：沿用点击 A、B 的操作，按 P 固定整组位置和统计值，轴下方标记两个端点。

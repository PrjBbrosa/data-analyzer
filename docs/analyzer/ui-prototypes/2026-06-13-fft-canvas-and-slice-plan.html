二、切片方案：FFT-vs-Time 与 阶次 都支持「横切 / 纵切」切换

核心：热力图有 X、Y 两个轴 + 颜色(幅值)。切片 = 固定一个轴，得到一条 1D 曲线。工具栏加一个切片方向切换钮。

切换按钮：工具栏加一个两态切换钮（如上图），点一下在「纵切(固定时间)」↔「横切(固定频率/阶次)」之间切换，按钮文字/图标随之变化。热力图上的红色标记线随方向变竖线/横线，可拖动实时刷新切片（也支持点击定位）。切片图的横纵轴标题随方向自动改。
v1 用单行/单列最近邻切片（和现状一致，最简单）；后续可选增强：拖一个窄带区间（在小范围频率/阶次上求平均）更稳。

UltraView / View library

不是多一层筛选，而是让五类分析在同一种月白石蓝里一眼可读

以下是对截图中 View 库的理解性重绘：保留搜索、分组、增删 View 与选中 View 的浮起反馈；移除“展开 / 概览”这层重复的架构切换，并将面板收至 360 px。五个正式分析区只使用月白石蓝的明度、冷暖阶梯，不再使用五种各自独立的彩色卡片。

① 四角持续可见最外层由单一圆角壳体负责 1 px 灰线，内容层不再覆盖边缘。
② 少一层，不少能力分组标题就是概览；点标题展开内容，不再在“概览 / 展开”之间重复切换。
③ 同源色阶，不是彩虹分类五类仅以月白石蓝的明度与冷暖层级区分；选中态始终使用同一蓝色浮起。

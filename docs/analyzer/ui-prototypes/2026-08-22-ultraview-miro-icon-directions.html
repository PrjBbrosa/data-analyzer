面向要在数据画布上快速创建、又不能误触标注的工程师。Miro 的有效之处是：左 rail 的图形足够大、形状轮廓足够独特、只有当前工具显蓝；不是“细线 + 彩色渐变”。本页把鼠标和激光笔一起放进四种完整的图标语言中比较。

B2 · REAL-RAIL REFINEMENT

方案 B 收敛：先对齐现有图标家族，再向 Miro 靠拢。

前一版 B 的 54 px rail、48 px 按钮和 3.2 px 笔画都不属于当前产品，因此天然“另起炉灶”。这一版严格使用现有 64 / 52、40 / 36、20 / 18 的视觉契约。

这次具体收掉的视觉偏差

所有主 rail 图标落在同一个 20 dp / 18 dp 坐标系；新加的 Pointer 不是另一枚 Font Awesome，而是和 Library / Grid 一样的 QPainter 线条语法。

  • 64 / 52沿用现有 desktop / compact rail 宽度。
  • 40 / 36沿用现有 desktop / compact hit target；每个图标的 X 中心完全重合。
  • 20 / 18沿用 icon size；既不把新图标放大成另一套，也不压小旧图标。
  • 1.7 px沿用当前 programmatic line icon 的圆端、圆角与笔画重量。
  • 6 / 4 gap沿用每组垂直节奏；divider 留白不再和按钮碰撞。
保留 Miro单一淡蓝 active、邻接 flyout、图标只表达手势。
不再使用主 rail 多枚渐变 active、不同字体库造成的光学跳动。

图标交付边界

这一版不是“所有东西都推倒重绘”。既有 Library / Grid / Layout / Filter / Unplaced 的程序化图标保持不动；只新增 Pointer 与 Laser，并让作者工具重用同一条 20 dp 路径、颜色和圆角语法。

PAINTPointer / Laser：新增 QPainter 路径，匹配既有 _line_icon(..., size=20) 机制。
KEEPSticky、Text、Shapes、Pen：保留已有程序化路径，调整的是状态与排列，不是另换一套字体图标。
QTA复制、锁定、删除、更多、缩放：继续是次级动作，可保留 qtawesome。

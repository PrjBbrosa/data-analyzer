开关说明
· 一个小开关浮在切片视图右上角，两段：X 切（竖线，固定时间）/ Y 切（横线，固定频率/阶次）。
· 点哪段就切哪个方向，标记线变竖/横，切片图横纵轴标题随之自动改。
· 标记线可拖动实时刷新，也可在热力图上点击定位。
· 下面那行小灰字(hint)显示当前固定值 + 切片含义，可保留也可去掉，你定。

若觉得「X 切 / Y 切」不够直观，也可改成「按时间 / 按频率」「按时间 / 按阶次」文字 —— 告诉我用哪种。

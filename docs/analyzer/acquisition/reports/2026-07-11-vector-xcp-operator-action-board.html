06 · Stop by failed stage

出错时按阶段停，不要盲调

先保存原始错误，再只改变一个变量。以下说明是定位路径，不是“继续录制”的豁免。

Runtime / import / 打包 smoke 失败
停止位置：不要连接 ECU。核对 64 位 Python、精确版本、动态 import probe、vendor dependency closure。源码能 import 而 exe 失败，退回 Task 10。
Vector bus open 失败
只检查物理/驱动层：驱动、设备识别、App 配置、channel、通道占用和 bitrate。不要改 XCP ID 或 DAQ selection。
XCP CONNECT timeout
检查：ECU 上电/点火、终端和线束、A/B A2L、CMD/RESP ID、bitrate、标准/扩展 ID。保存 timeout 和实际使用 ID。
DAQ locked / Seed&Key 失败
检查：GET_STATUS protection 结果、DLL 路径/位数/符号、是否与 ECU 软件版本匹配。不要从 CONNECT RESOURCE 位推断锁状态。
DAQ started，但持续没有 DTO
这不是连接成功。检查 event、list selection、START_STOP_DAQ_LIST、START_STOP_SYNCH、pyxcp acquisition policy 是否安装，以及 ECU 是否实际触发该事件。退回 Tasks 4–5。
收到 DTO，但 unknown PID / malformed payload
检查：ECU 返回的 firstPid、ODT 数量、MAX_DTO、timestamp mode、identification field 和 address extension。不要假设 PID 从 0 开始。
数值不合理或单位不对
检查：signedness、byte order、datatype、COMPU_METHOD、转换是否被重复/遗漏、unsupported conversion 是否被错误标成物理量。保存 raw 与 decoded 对照。
MF4 存在但重开失败 / 样本不对 / 有 drop
本轮失败。分别查看 frame overflow、sample overflow、decode drop、ring drop、writer error 和 bus error。不要用“文件生成了”作为 PASS。

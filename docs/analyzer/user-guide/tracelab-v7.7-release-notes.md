# TraceLab 7.7 发布说明

TraceLab 7.7 扩展了工程数据导入范围，并提供更小的纯分析 Windows 包。应用内使用说明和四个分析面板指南已用当前 v7.7 真机界面重新渲染。

## 新增数据格式

- **WinWert `.wwt`**：读取原生 WinWert 测量文件，以 `Zeit` 通道定义的采样间隔和起点建立时间轴，保留通道单位、比例和偏置；计算参数与公差/评价曲线不会被误当作测量通道。
- **ZFGE2 / TestRunPRO `.zfd`**：读取文本头和 float32 通道块。优先使用文件中的采样间隔；信息无效时以 1 kHz 回退，并在数据状态中标记采样率为估算值。
- **MATLAB `.mat`**：支持 v4-v7，并通过 HDF5 回退读取 v7.3。数值向量和矩阵列可作为通道；只有 `t`、`time`、`zeit` 等明确时间变量会用于建轴。MAT 文件没有可靠工程单位时保持为空，不猜单位。

ASCII（`.asc` / `.fdc`）与 NI TDMS（`.tdms`）继续沿用 7.6 的严格时基规则；`.tdms_index` 仍只是配套索引，不能单独打开。

## Windows 包

- **完整包 `TraceLab7.7`**：包含 Analyzer 与采集相关能力。
- **轻量包 `TraceLabAnalyzer7.7`**：保留离线分析和现有数据导入，去除采集依赖；用户进入不可用的采集入口时会收到明确说明。
- Windows 构建排除了当前运行路径未使用的 Qt 模块和纯分析包不需要的科学绘图库，以缩小分发体积；发布前仍需分别完成启动、导入与分析冒烟验证。

## 使用建议

1. 导入 WWT 后，抽查文件卡片中的采样率、时长和通道单位。
2. 导入 ZFD 后，如界面提示采样率为估算值，请先与试验配置核对再做频域分析。
3. 导入 MAT 后，确认软件选中的时间变量与待分析通道长度一致；缺失单位需要由使用者补充上下文。
4. 需要采集功能时选择完整包；只做离线分析时可选择 Analyzer 轻量包。

7.6 的 ASCII、TDMS 与 12 个时域 View 说明保留在 [`tracelab-v7.6-release-notes.md`](tracelab-v7.6-release-notes.md)。

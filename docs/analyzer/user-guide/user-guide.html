6 · 预设栏（FFT / 阶次 / FFT vs Time）

6 个槽，1 键存当前所有参数，下次 1 键还原。

左键

加载 该槽保存的参数到当前 Inspector。槽是空的就提示。

长按 / 右键 → 保存

把当前所有参数写入该槽，并起一个名字。

右键菜单

重命名 / 清空 / 重置为内置默认 / 导入导出。

悬停看摘要：鼠标停在槽上，会弹出该预设的参数清单卡片，不用点开就能确认是不是要的那一个。

实拍：预设栏长什么样

7 · 批处理抽屉

对多个文件跑同一套 Pipeline，结果统一写到一个目录。

① Input · 输入

+ 已加载 从主界面已经打开的文件中选；+ 磁盘… 直接从磁盘加。可设时间范围。

② Pipeline · 步骤

勾选要跑的分析（时域 / FFT / 阶次…），每个分析可单独配参数。可用 从当前单次填入 把主界面的 Inspector 配置一键复制过来。

③ Output · 输出

选输出目录，决定生成 Excel / PNG / CSV 等。默认在 ~/Desktop/mf4_batch_output。

底部按钮

运行中：任务列表会显示进度 N/total 和预估剩余时间。点 中断 后按钮会变成"正在停止…"，等当前一项跑完才真正退出。

8 · 常见问题

点开看答案。
Inspector 不见了怎么办？
工具栏最右边那个 Inspector 按钮是开关，点一下就显示/隐藏。变灰说明已关闭。
切换模式后参数怎么变成默认了？
不会。Inspector 会缓存每个模式上一次的输入，切回去时自动还原。如果你看到的是默认值，可能是这个模式还没碰过 —— 或者你点了"重置为内置"。
Fs（采样率）显示和我预期不一样？
Fs 从所选通道自动同步。换了通道，Fs 跟着变。FFT vs Time / 阶次模式下，换信号时 Fs 字段会自动更新。
FFT vs Time 跑得慢，能中断吗？
能。计算在后台线程跑，每一帧都会查取消标志。运行中再次点该按钮即可取消，或切走当前模式也会触发取消。
中文显示乱码 / 方块？
软件会自动选择可用中文字体。若仍显示方块，请在系统中安装 PingFang SC、Microsoft YaHei 或 Noto Sans CJK SC 后重启。
预设保存在哪里？换电脑能带走吗？
预设保存在当前用户的应用配置中。要带到另一台电脑，请用预设栏右键的 导出（或批处理抽屉的“导出预设”）。
图复制出来粘到 PPT 里没有游标和读数？
用图表工具栏的 📋 复制为图片，它会把当前可见的游标线和读数一起复制。
多个文件叠加，但有的文件没有那个通道怎么办？
缺通道的文件会被跳过，状态栏会提示。建议先用 编辑通道 抽屉把不同文件里通道名对齐（重命名），再叠加。

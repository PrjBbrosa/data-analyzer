# TraceLab 7.6 发布说明

发布日期：2026-07-16

## 新增数据导入

- **ASCII `.asc`**：支持逗号、分号、制表符等分隔表，以及具有稳定数值列布局的固定宽度 ASCII。分隔表必须有可识别的时间列；固定宽度表必须包含已验证的采样间隔。软件不会把未知文件默认当作 1 kHz。
- **NI TDMS `.tdms`**：导入非空数值波形通道，保留通道单位与中文名称，并由 `wf_increment` 和可选 `wf_start_offset` 生成时间轴。没有可靠波形时基的 TDMS 会明确报错，而不是伪造采样率。
- **配套文件**：`.tdms_index` 是 TDMS 的索引配套文件，不能单独打开。
- GUI 拖放/打开和批处理使用同一套 ASCII、TDMS 识别规则。

## 时域 View 扩容

- 时域工作区最多可创建 **12 个 View**，每个 View 继续独立保存通道、缩放、游标、布局和标签颜色。
- 宽度足够时显示完整 View 名称；空间不足时自动改为紧凑的编号标签，完整名称保留在悬浮提示中。
- 标签仍放不下时，尾部 View 收入 `»` 菜单；菜单可切换任意 View，当前激活的 View 保持可见。
- 右键复制、重命名、改标签颜色、拖动排序和“与此 View 并排”操作保持不变。

## 打包与依赖

- Windows 打包默认名称为 `TraceLab7.6.exe`。
- 基础 TDMS 读取依赖为 `nptdms==1.11.0`；PyInstaller 已显式收集该延迟导入模块。

## 快速验证

1. 打开 `.asc` 或 `.tdms` 后，确认左侧通道树、单位和时间范围符合源文件。
2. 对 TDMS，确认状态信息的采样率来自文件波形时基。
3. 连续点击时域 View 的 `+`，最多创建 12 个；缩窄窗口后用 `»` 切换被收纳的 View。

① 通道编辑

从已有通道派生新通道、合并两路信号、删除用不到的通道。所有结果都属于当前文件，不会写回原始 MF4。

1. 在哪打开

  1. 左侧 FileNavigator 里先选中一个文件（蓝色高亮）。
  2. 右键文件 → 通道编辑；或者用顶部工具栏的"通道编辑"按钮。
  3. 右侧滑出抽屉，标题写着 通道编辑 — <文件名>。
抽屉是独占的：一次只编辑一个文件。要给另一个文件加通道，先关掉再选下一个。

2. 单通道运算

用一个源通道生成一条新曲线。源通道可以选已有通道，也可以选你刚刚在本次编辑中创建的新通道。

运算含义参数新通道名前缀
d/dt对时间求一阶导数无（参数留空）d_dt_
∫dt对时间积分（梯形法）无int_
× 系数整体乘一个常数，比如换单位系数（任意数）scaled_
+ 偏移加一个常数，做零点对齐偏移量offset_
滑动平均等长低通平滑窗长（≥ 3，取整）mavg_
|x| 绝对值取每个样点的绝对值无abs_

点 ✚ 创建通道 后，右下角 新增: N 会 +1，且新通道立刻出现在三个下拉框里（源、A、B），可继续拿它派生。单通道 / 双通道两区按钮文案相同，区别只在运算用几条源。

源EngineSpeed
运算d/dt

✚ 创建通道→ 新增通道 d_dt_EngineSpeed

3. 双通道运算（A ⊕ B）

把两条通道做对应位运算，长度必须完全一致——这是最常见的报错来源。

运算说明
A + B逐点相加
A − B逐点相减
A × B逐点相乘（如功率 = 扭矩 × 角速度）
A ÷ B逐点相除，B = 0 处自动取 0（不报除零错）
max(A, B)逐点取较大值
min(A, B)逐点取较小值

新名称留空时按 <op>_<A>_<B> 自动生成（例：add_torque_speed）。重名时尾部自动接 _1、_1_1……

单位合并规则：

  • A 和 B 单位相同 → 新通道沿用同一单位（如 Nm + Nm = Nm）。
  • A ÷ B 且单位不同 → 新单位写成 unitA/unitB。
  • 其他组合 → 新单位为空，需要你后续手填。
长度不匹配会弹红框 通道长度不匹配: 8000 vs 7999。原因通常是这两条通道来自不同采样率的源——先用 横坐标转换 / 重建时间轴 对齐采样率。

4. 删除通道

  1. 在底部列表里多选要删的通道（按住 Ctrl 或 Shift）。
  2. 点 🗑 删除，确认后从列表移除。
  3. 删除是会话内的：点对话框右下 确定 才真正生效；点 取消，全部新建/删除回滚。
建议工作流：先创建好所有派生通道、确认右下角"新增"数对了，再统一删除冗余通道，最后点 确定。这样误操作可以一键 取消 全部撤销。

② 横坐标转换

默认横坐标是时间（秒）。你可以换成"任意一条通道"作横坐标，或者在采样率信息缺失时重新指定 Fs 来重建时间轴。两件事，分两个入口。

A. 用其它通道做横坐标（X 轴 ↔ 通道）

常见场景：

  • 把 扭矩 vs 转速 画成 MAP 曲线，而不是按时间走。
  • 分析某个温度对压力的依赖关系。
  1. 在右侧 Inspector 顶部，把"横坐标模式"切到 通道。
  2. 展开候选列表，挑一个通道——条目前面带方括号文件名前缀，例如 [run1.mf4] EngineSpeed。
  3. （可选）在标签输入框里写 X 轴显示名，例如 转速 (rpm)。留空则用通道名本身。
  4. 按下方"应用"按钮（或回车），所有曲线立即重画。
长度必须一致：候选通道的长度必须等于所有当前被勾选绘图的通道。否则会弹出 toast 横坐标通道长度与当前绘图通道不一致，X 轴不会被切换。

B. 如何切回时间轴

把模式切回 时间 → 应用。X 轴恢复为秒，所有自定义 X 通道引用会被清空。

C. 重建时间轴（修改 Fs）

有时 MF4 里没有可信的时间列（导出工具丢了时间戳，或时间不单调）。这时候要给文件指定一个采样率，由分析器按 t = i / Fs 生成均匀时间数组。

  1. 右侧阶次面板 信号源 卡片右上角有个小图标按钮 ⟲，鼠标悬停显示"重建时间轴"。
  2. 点开后弹出一个浮窗：
    重建时间轴 · 浮窗
    目标：[run1.mf4]
    Fs1000.00 Hz
    取消 确定
  3. 填入正确的采样率（如 1000 Hz），按 确定，分析器会把这个文件的 time_array 重新生成为 0, 1/Fs, 2/Fs, ...。
Fs 范围：浮窗里允许 1 Hz ~ 1,000,000 Hz；通常车辆 CAN 数据在 100–1000 Hz，振动加速度可达 10 kHz~50 kHz。
什么时候要重建？ 阶次分析 / FFT 都依赖均匀采样。如果你的 MF4 是非均匀时间戳，先重建一次再算阶次，结果才有意义。

D. 模式切换的连锁反应

切换 X 轴模式或重建时间轴时，分析器会自动：

  • 清空时域曲线的 envelope cache（视觉抽稀缓存）。
  • 清空单调性缓存——X 轴可能不再单调递增。
  • 清空 FFT vs Time 缓存——时基变了，旧热图作废。
  • 立即重画时域图。

所以"切换后第一次画图会略慢"是正常的，不是卡死。

③ 阶次（Order）计算

分析与转速同步的周期成分——发动机点火阶次、齿轮啮合阶次、变速比下的轴承故障特征。算法是 COT（Computed Order Tracking，计算阶次跟踪），结果是一张"时间 × 阶次"热图。

1. 直觉理解：什么是"阶次"？

阶次（Order）是每转出现的次数。例如 4 缸 4 冲程发动机的点火阶次是 2 阶（每转点火 2 次）。同一条振动信号，频率会随转速变，但阶次不变——所以阶次图比 FFT 图更适合变工况。

频率 (Hz) = 阶次 × RPM / 60
# 例：转速 3000 rpm，2 阶 → 频率 = 2 × 3000/60 = 100 Hz

2. 切到阶次模式

  1. 顶部工具栏切到 阶次 模式（或叫"时间-阶次"）。
  2. 右侧 Inspector 出现 OrderContextual 面板：信号源、谱参数、坐标轴设置、预设栏、"时间-阶次"主按钮。

3. 信号源配置

字段填什么注意
信号要分析的振动 / 噪声通道（加速度、力等）支持搜索，可选派生通道
转速转速参考通道，单位 rpm没有 rpm 就先做个换算通道（× 60、× 系数等）
Fs该文件的采样率 (Hz)会跟"重建时间轴"联动
RPM 系数转速通道的标定系数实际 rpm = 通道值 × 系数；默认 1
转速可以为负（反转）但不能全是 0。COT 用累积角度来重采样，全程 0 转速会直接抛出 RPM is zero throughout the signal — COT cannot resolve orders。

4. 谱参数详解

字段取值范围默认选大 / 选小的影响
最大阶次 1 – 100 20 越大算得越远，但受 Nyquist 限制——超过 fs/2 ÷ (rpm_max/60) 的阶次会被自动屏蔽
阶次分辨率 0.01 – 1.0 0.1 越小越精细（行越多），但内存占用线性上升；常用 0.05–0.25
时间分辨率 0.01 – 1.0 s 0.05 s 越小时间方向越平滑但帧数翻倍；建议 0.02–0.1 s
FFT 点数 (nfft) 512 / 1024 / 2048 / 4096 / 8192 2048 越大频率/阶次分辨率越高，但慢；信号必须覆盖足够圈数
每转样本数 64 – 2048 256 角度域重采样的密度；越大对高阶次更准，但内存线性增长
经验配方（家用车 1–6000 rpm，振动信号 Fs=10 kHz）：最大阶次 20、阶次分辨率 0.05、时间分辨率 0.05 s、nfft 2048、每转样本数 256。先按这个跑，再按需要微调。

5. 坐标轴设置（Y = 阶次，Z = 幅值色阶）

  • X 范围（时间）：默认 全时段，勾掉 auto 就能锁定显示窗口。
  • Y 范围（阶次）：默认 0 → 最大阶次，上限自动跟"最大阶次"联动——你改谱参数它会跟着改。
  • Z 范围（色阶）：默认 dB 范围 −50 → −10，关掉 auto 后可手动指定 floor / ceiling。dB 模式更适合查看微弱阶次成分。
  • 幅值单位：可切 Amplitude dB / Amplitude，前者是 20·log10。

6. 跑一次完整阶次分析

  1. 左侧勾选要分析的振动通道（决定可在"信号"下拉里选谁）。
  2. 切到 阶次 模式。
  3. 填完信号、转速、Fs、RPM 系数，确认它们都来自同一个文件。
  4. 谱参数先用默认；如果转速变化范围很大，把"时间分辨率"调到 0.02 s 以捕捉瞬态。
  5. 点 时间-阶次 主按钮。状态栏出现 计算时间-阶次谱 (COT)...
  6. 完成后中部画布显示热图，状态栏给出 N 时间点 × M 阶次。

7. COT 内部到底做了什么

了解流程能帮你判断哪些参数该调：

# 1. 把瞬时角速度积分成累积角度
ω(t) = |RPM(t)| · 2π / 60
θ(t) = ∫ ω(t) dt

# 2. 把信号按等角度间隔 dθ = 2π / samples_per_rev 重采样
s(θ) = interp(θ_uniform, θ, signal)

# 3. 角度域加窗 FFT，bin k 直接对应阶次 k·(samples_per_rev / nfft)
X[k] = FFT(s · window)[k]

# 4. 插值到用户指定的阶次网格 (max_order, order_res)

因为是角度域取频谱，"阶次"是 FFT 的天然刻度——转速怎么变，阶次峰都在同一行上，不需要 RPM 后处理。

8. 性能与边界

  • 低于 min_rpm_floor = 10 rpm 的帧会被置零，避免 0 转速段噪声爆掉色阶。
  • 计算是同步跑在 UI 线程上的，长信号 / 高 nfft 会短暂卡顿——暂时无法中途取消（"取消计算"按钮是占位，未来异步化时会启用）。
  • 每批最多 256 帧并行 FFT，控制峰值内存在 ~32 MB 以内。
  • 正反转会被 |RPM| 绝对值化，正负方向落到同一阶次。

9. 出错排查

错误 / 现象原因怎么修
RPM is zero throughout the signal 全段 RPM = 0 检查 RPM 通道值；如果它实际单位是 Hz，把 RPM 系数填 60
signal covers only N revolutions 信号长度不够 nfft 个等角度样本 减小 nfft 或每转样本数；或截取转速较高的时段重跑
length mismatch: sig=… rpm=… t=… 三个通道长度不一致 用 重建时间轴 或 通道编辑 对齐
time vector must be strictly monotonically increasing 时间戳有抖动 / 倒退 对该文件做"重建时间轴"，用均匀 Fs 网格替代原 MF4 时间
热图低阶次区域全是噪声横纹 低阶次频率落进 FFT bin 宽度以下 正常现象——分析器已经按 df = fs / nfft 自动屏蔽不可分辨阶次，但 COT 路径不做这层屏蔽。可以把"最大阶次"调低、视觉范围放在 0.5 阶以上

常见问题（FAQ）

Q1. 通道编辑里创建的新通道，关闭文件后还在吗？

不在。所有派生通道存在内存里的 FileData 上，关闭文件即丢失。如果要保留，导出为 Excel/CSV，或在批处理里把这套派生写进预设。

Q2. 切到"通道做横坐标"后，FFT / 阶次能用吗？

FFT 与阶次分析始终基于时间采样的信号，不用当前 X 轴。所以你可以一边用扭矩做横轴看 MAP，一边在阶次面板里照常分析振动通道——两者互不干扰。

Q3. "重建时间轴"后原始时间戳会被覆盖吗？

会。FileData.time_array 被替换成均匀网格；这是会话内的修改，不会写回 MF4 文件。重新打开文件即恢复原始时间。

Q4. 阶次面板里改完最大阶次，Y 轴上限没动？

谱参数里的"最大阶次"会自动联动 Y 轴 spin_y_max 的上限，但你之前手动设过的具体值不会被改写。把 Y auto 重新勾上即可让它跟随最大阶次。

Q5. 双通道运算的结果单位为什么是空？

除了 A÷B 和 A、B 单位相同的情况，工具不去猜单位（避免把 Nm × rpm 错写成 Nm·rpm）。运算完手动到导出对话框里改一下名字与单位就行。

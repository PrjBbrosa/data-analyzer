P1 问题

优先级 问题 证据 建议
P1 内联 QSS 和 raw color 过多，影响全局一致性。 markup/editor.py:864-884、1055-1078、1138-1150；markup/thumbnail.py:72-107；signal_picker.py:114-195 通用按钮、popup surface、swatch、thumbnail 样式迁回 style.qss 或 UI kit。
P1 弹层验证门槛不统一。 test_rebuild_popover_geometry.py:84-100 已覆盖 shell/surface；test_batch_signal_picker.py:203-214 和 test_markup_editor.py:293-303 只覆盖透明背景。 测试分三档：结构、shell flags、截图/像素/实机视觉验证。
P1 控件密度规则需要分层。 标注编辑器工具按钮 44x44；图表 toolbar 32x32；缩略图关闭按钮 22x22；侧栏 rail 12px。 工具按钮默认 44x44；桌面 chart toolbar 可 32x32；关闭/危险按钮至少 30x30 hit area；侧栏 rail 必须有 hover/click 反馈。
P1 旧入口仍混有 emoji/文本图标。 dialogs.py:64-102 有 ✚ / 🗑；replay_tab.py:110-123 有播放符号文本；主 toolbar 已经使用 ui_kit/icons.py。 保留中文文本，装饰性符号换成统一 Icons / qtawesome，避免跨平台字体差异。

推荐执行路线

Phase A：先修线宽菜单

  1. 给 markupStyleMenu 增加 native-shadow flags。
  2. 保留透明 menu shell + 内部 markupStylePanel。
  3. 更新 test_markup_editor.py，断言 FramelessWindowHint / NoDropShadowWindowHint。
  4. 做真实 GUI 检查：打开图片标注编辑器，点样式/线宽菜单。

Phase B：统一 popup/menu helper

  1. 新增 mf4_analyzer/ui_kit/popup.py。
  2. 提供 style_popup_shell(...)。
  3. 迁移普通 QMenu、SignalPickerPopup、标注样式菜单。
  4. 新增结构测试，避免新圆角菜单缺 shell flags。

Phase C：全局视觉收敛

  1. 内联 QSS 中的通用形态迁回 style.qss。
  2. 旧 emoji 按钮换统一图标。
  3. 给 MarkupEditor、Chart toolbar、Side panels、Acquisition toolbar 做截图/实机 pass。

建议的 popup helper 形态

目标不是到处复制几行 flags，而是把圆角弹层的外壳规则收进一个入口。

1. 保留原行为 不破坏已有 Qt.Popup、dismiss、定位和父子关系。
2. 抑制原生阴影 追加 FramelessWindowHint 与 NoDropShadowWindowHint。
3. 透明外壳 最后设置 WA_TranslucentBackground，避免 flags 变更重建窗口后属性丢失。
4. 内部 surface 可见白底和圆角放到内部 QFrame / panel，避免透明 QDialog 中心不绘制。

新规则草案

UI-R1
任何圆角 popup/menu/popover 都必须是透明外壳；可见白底放内部 surface。
UI-R2
macOS 顶层 QMenu / Qt.Popup 若有圆角，必须处理 FramelessWindowHint | NoDropShadowWindowHint。
UI-R3
弹层视觉问题不能只靠 attribute 测试结案；至少需要结构测试 + 实机截图/像素/现场检查之一。
UI-R4
业务模块不要新增大段内联 QSS；通用按钮、菜单、浮层、swatch、thumbnail 样式沉到 UI kit。
UI-R5
icon-only 工具默认 44x44；桌面图表 toolbar 可 32x32，但必须有 tooltip、active state 和键盘/菜单替代路径。
UI-R6
TraceLab 是工具型桌面应用，后续 UI prototype/方案必须贴近现有产品界面，不做 demo page 或营销页风格。

当前未验证

  • 本轮没有打开真实 TraceLab GUI，也没有截图验证线宽菜单；结论基于代码路径、已有 tests 和 lessons。
  • 普通 QMenu 构造点是否全部肉眼可见方形阴影，需要 Phase B 后用真实 macOS 菜单逐个抽查。

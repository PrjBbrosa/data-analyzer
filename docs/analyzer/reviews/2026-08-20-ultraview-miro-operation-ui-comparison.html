Rail：不是尺寸不够，是强调和节奏没有 owner

用户要求拉开图标间距；当前真实布局的组内 gap 为 0 px，divider 仅 1 px。同时多个状态共用高强度渐变。

01 · Select 是有意偏离

Miro 官方说明 Select/Hand 不能从 Creation toolbar 移除；TraceLab 用户明确不要可见鼠标按钮，因此保留内部 Select + V/Esc 即可，不应重新加回。

02 · 0 px 组内间距

1280×720 与 800×560 的 offscreen 实测均为按钮直接相接；divider 只产生 1 px。整改应增加 6/4 px，而不是继续放大按钮。

03 · 多枚 primary fill

Free Grid、Layout panelOpen、Draw active 可以同时成立。Miro 的创建栏是当前工具焦点；TraceLab 需要把 persistent mode 降成 quiet marker。

04 · 点击后变纯青

author active 本身是钛蓝—琥珀，但 active:hover/pressed 又改成纯色；鼠标不移开时用户看不到琥珀端。

05 · 光学尺寸仍跳

按钮 outer rect 已稳定，但 Sticky/Text/Shapes/Draw 使用不同 Font Awesome Solid glyph；Draw 还随子工具换入口 glyph，视觉重量持续变化。

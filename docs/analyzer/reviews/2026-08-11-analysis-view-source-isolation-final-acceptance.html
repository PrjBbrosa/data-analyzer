本轮发现并修复的两个问题

R1 · 程序化 View restore 提交冷缓存计算

Order View 应用保存的 dB reference 时发出 valueChanged，延迟执行用户编辑回调， 冷缓存进一步提交 worker。现在 _on_db_reference_value_edited() 在 _applying_analysis_view / preset apply 期间不响应。新增测试在修复前红、修复后绿， Task-10 最终记录 0 次 submit_batch。

R2 · 项目重开后隐藏时域覆盖分析 owner

项目保存于 FRF View 2，重开后画布与 Inspector 已是 FRF，但左栏写成“时域 · View 2”。 根因是最后的 Time manager restore 在非时域模式仍投影共享 navigator。现在仅当可见模式为 time 时投影时域控件；offscreen 回归与真实 Cocoa 均恢复为“FRF · View 2”。

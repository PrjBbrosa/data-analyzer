## 1. 总评

**主干方向正确、契约化程度高（每簇都有 spec + plan + 红测先行），但有 1 条 P0、
8 条 P1，并且全量测试门禁当前被一个测试基础设施缺陷阻断。** 问题呈四类：

1. **做了一半的契约**：脏态守卫覆盖了 View / 过滤 / 撤销重做，但漏掉标注与视角
   （C1）；Smart Layout 的 fixed-point 校验把「非幂等」做成了「拒绝服务」（B1）；
   命令注册表声明自己是单一事实源，但 hints / quickref / 图表复位仍是手写副本（C5）。
2. **macOS 平台语义未验真机**：`Ctrl+Tab` 在 Qt/mac 是 ⌘⇥，被系统应用切换器抢走
   （C2）；无 QMenuBar 时 Cocoa 应用菜单 Quit 很可能绕过守卫（C3，UNVERIFIED）。
3. **状态 owner 与生命周期**：溢出面板 Esc 关闭后不释放（D2）、pill 避让在投影
   更新后失效（E2）、轴组仍双 owner 且用户编辑不持久化（F2）、卡片锁只活在运行时
   （B5）、`_reset_empty_workspace_session` 绕过 ViewManager（F4）。
4. **护栏流失与死代码**：删除 1000 行 WWT 原生渲染测试后 `_initial_xlim` 重叠分支
   零覆盖（F1 因此漏网）；WWT→UltraView 原生布局链路在 `fb8b6cf8` 后已无生产调用
   却整套保留（F6 / B2 / B4）；`test_wwt_inplace` 在模板缺失时静默 skip（A2）。

机械护栏（状态所有权棘轮、backref 不变量、三层分层、signal 无 GUI、批渲染边界、
原生依赖惰性化、打包导入、QSS border 简写、lambda 棘轮、conftest 作用域、QSettings
隔离）在 HEAD 上 **45 passed / 1 skipped**，全部守住。

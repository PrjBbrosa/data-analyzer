自动模式 A

切换通道时重新解析。按钮右下角显示蓝色 A；输入框可编辑，但一旦手输即进入手动模式。

手动模式 M

手动值属于当前分析 View，不被通道切换或全局默认修改覆盖。按钮显示琥珀色 M，菜单中可“重新跟随默认”。

混合单位

FFT 多曲线解析出不同 reference 时不得静默用第一条；轴显示“per-curve reference”，每条曲线在图例/提示中标出自己的值。

DEFAULT MANAGER

DONE MEANS

验收标准：不是“按钮出现了”，而是 reference 从输入到输出闭环

以下条件全部满足，才能把功能标为完成。

三类分析的 dB reference 行右侧都有同尺寸按钮，窄 Inspector 不换行、不挤压输入值。
1e-12、1e-9、1e-6 均可输入、保存、恢复和重新显示，不被舍入为零。
自动模式切换 Pa / m/s² / m/s / m / N 时，reference、来源说明和结果标签同步变化。
合法 HDF metadata 默认优先；关闭“优先通道元数据”后改走用户/系统目录。
用户编辑默认值后，Auto View 重新渲染；Manual View 完全不变且不触发重新计算。
A 计权 + dB 在 FFT、色标、切片轴、批处理图片中全部显示 dBA；线性模式不冒充 dBA。
旧 preset/project 缺少新 mode 字段时不把 weighting 或 reference 重置成硬编码值。
不同 reference 的 FFT overlay 明确显示 per-curve reference，不产生看似同量纲的假比较。
db_reference/catalog 修改不改变 compute cache key；weighting 修改仍会得到新的计算缓存。
目标测试、项目往返、batch 图片、离屏几何检查与 macOS 实屏截图均通过。
建议的正式落地顺序：先把这份 draft 评审定稿，再写 SPEC + PLAN；实现时按 Batch A → B → C，避免 UI 先落地而标签、持久化或 batch 仍使用旧语义。

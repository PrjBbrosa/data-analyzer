# 坐标刻度宽度与边缘可见性 Spec

日期：2026-09-09
状态：设计完成，产品实现未开始；本轮仅编写文档。
配套：[执行 Plan](../plans/2026-09-09-axis-label-width-and-edge-visibility-plan.md)

## 1. 目标与范围

修复用户在 WWT 批量预览中发现的 Y 轴数字缺失、标题与刻度重叠，并覆盖横查中确认的同源问题。合并方式、字体大小和数值位数不能使已选刻度因轴宽不足而静默消失。

范围包括：

1. Batch 时域分屏的左轴，含只有一个子图的情况。
2. Batch FRF 幅值、相位、相干性三联图的左轴。
3. Batch 与主界面 FFT-vs-Time / Order 热图色条的数值轴。
4. Batch 热图切片 X 轴靠近边缘的标签：纳入独立诊断和修复步骤，不能假定与左轴宽度同因。

不改 WWT 解析、数据分组、DSP、采样时间、工程单位、曲线数组、用户指定范围、色阶值或预设 schema；不改产品版本。不扩大到全画布重构或历史所有端点缺字问题。已有主界面左轴测宽实现作为复用对象及回归消费者，不重新设计。

## 3. 尺寸与绘制合同

### 3.1 最终刻度先于轴宽固定

- 共享测宽以 `mf4_analyzer/ui_kit/axis_metrics.py` 的 `left_axis_width_for_ticks`、`pin_left_axes_to_common_width`、`activate_item_layouts` 为现有权威。
- 测量包括当前刻度字体、当前实际字符串、tick offset、向外 tick length、可见旋转轴标题所需空间。不得只依赖 `AxisItem.textWidth` 的上一次绘制缓存。
- 最终范围、字体、标题及显式刻度确定后，再执行共同轴宽计算；激活每个拥有轴的 PlotItem 布局以及外层 GraphicsLayout。
- 所需宽度不得通过缩短精度、删除较长标签、改变手动范围或缩小用户所选字体规避。
- 原有自适应刻度密度继续决定选择哪些刻度。本合同要求被选中且应绘出的内部标签完整，不强制显示每个候选 minor tick。
- 时域单子图的 `subplot` 也必须测宽；FRF 三行最终左边缘一致。绘图区可为足够的轴空间合理缩窄，但 X/Y 数值范围不变。
- 首次导出即正确；重新生成、重复 settle 不累积边距，不依赖用户拖动、额外 sleep 或反复 processEvents 才补齐。
- 保留当前公共辅助函数在同一对齐过程中的“不窄于已实现宽度”语义；不扩展为新的自动收缩策略。

### 3.2 色条数值轴

- 色条保留原方向、单位、调色板、level 值和格式规则，解除库默认数值轴固定宽度，允许真实文字占用空间。
- 注意色条右轴负责数值，左轴负责标题，不可套用“普通右框架无数值”的假设，也不能误释放色带本身的固定宽度。
- 按最终色阶和字体进行尺寸收敛；Batch 首次导出、主界面初次显示、重绘复用、切换色阶范围和标签后均正确。
- 主界面测试覆盖 `plot_or_update_heatmap` / 实际更新入口和色条 level 变更，不能只在构造器测试。交互拖动色阶手柄时保留现有 signal、owner 和防重入规则。
- 图例、色条标题和数值须位于导出页面/画布有效区域；切片与主热图的左右对齐应在色条新尺寸确定后仍成立。
- 不改 `site-packages` 或全局 monkeypatch pyqtgraph。若自动尺寸不能保证首次绘制，应在现有 owning 路径按真实字符串预量并激活布局；共享辅助仅在两消费者语义相同且有测试时增加。

### 3.3 切片 X 轴边缘

D4 必须先记录：最终 X 范围、显式 tick 位置、字体、轴/视图/页面矩形、实际 textSpecs，以及标签相对边缘的余量。区分字体宽度、QPicture 缓存、布局时序和 `boundingRect` 裁剪；历史网格 Y 轴端点问题不能直接当成其原因。

目标是：最终选择的边缘附近内部主刻度完整可读，与相邻数字不重叠且不画出页面；不靠扩展用户数据范围、篡改标签值、把 475000 特判掉来通过。若最终位置碰撞检查需要重新选择更稀的 nice-step，应在统一 tick fitter 完成并保证整个范围一致，不能依靠绘图库逐条静默丢弃。

只改负责该行为的 Batch 布局/刻度路径。若确实需要修改共享 AxisItem 裁剪、主界面交互轴或全局格式算法，先补充本 Spec 的消费者与验证范围，再实施；此步骤在原因尚未确认时不得标记完成。

## 4. 兼容与非回归

- 输入与导出 DTO 的 X/Y、复数 FRF、coherence、热图矩阵和色阶不变；保留 FRF 线性/dB、log/linear X、wrapped/unwrapped phase 语义。
- 自定义 X、手动范围、双单位轴、分组身份不变。已正常的叠加、普通 FFT、切片 Y 轴及跨 pane 对齐不得退化。
- 不修改 `signal/`、Batch runner / reporter、持久化状态或 MainWindow owner。新增可变状态必须有单一 owner 和对称清理。
- 未新增或重命名用户交互，不要求修改 `ui/hints.py` / `ui/quickref.py`；若后续设计增加交互，再同时更新两者。
- 像素变化只应来自必要的文字/布局修正；不要求错误图片 byte-identical。保留现有导出 DPI、抗锯齿、颜色与数据完整性合同。

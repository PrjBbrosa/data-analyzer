# TimeDomain 轴空间恢复与模式切换首帧稳定性 Spec

日期：2026-09-05

状态：**设计草案；尚未授权实施，运行时验收未完成**

配套：[执行 Plan](../plans/2026-09-05-timedomain-axis-layout-first-frame-plan.md)

## 1. 目标与范围

解决时域画布两类体验问题：

- A：分屏取消通道到只剩原上层行时，绘图区挤占底部横轴空间，刻度消失、标题进入绘图区。
- B：用户报告分屏／叠加切换先铺满绘图区、再出现横轴并收缩，引起闪烁。

A 已有当前代码与原生 Cocoa 复现；B 有用户观察，但完整应用的逐帧原因仍为 UNKNOWN。
本 spec 规定最终行为，不预先将 B 归因于 A、字体首绘、事件重入或 AA。
本轮交付仅为本文和 Plan，禁止据此直接修改产品代码。

范围：TimeDomain 的分屏选择增量更新、分屏／叠加全量重建、底轴角色变化与首次展示。
保护近期已修复的两曲线共轴显示、逐曲线着色图例和 Custom-X 双游标差值。
不扩展到 FFT/FRF/Order 画布、Batch renderer，不新增动画、布局设置或持久化字段。
不为每个 View 常驻独立画布，不重写数据加载、DSP、渲染质量算法或通道身份。

## 2. 已核验的事实与证据边界

分析时 HEAD 为 `37081b15`，工作树包含本会话与其他并行会话的未提交修改。
此标识不是干净快照；实施前必须重新记录 HEAD、相关文件摘要和 dirty scope。

| 证据 | 当前结论 | 限制 |
|---|---|---|
| 用户三通道→单通道截图 | 第一行成为唯一行后横轴刻度消失，标题进入图面 | 静态图不能证明绘制时序 |
| 原生 Cocoa 合成数据探针 | 原第一行底轴固定高度仍为 1；正常单图为 36.8 logical px | 数值属于该字体／机器，不是产品常量 |

| 独立探针仅在内存解除固定高度 | 底轴恢复 36.8，标题和刻度恢复；未改源码 | 因果验证，不代表修复已交付 |
| 独立 Cocoa 分屏↔叠加探针 | 返回时至随后 paint 的底轴高度稳定，未复现 B | 不能以此否认完整应用里的闪烁 |

### 2.1 A 的调用链

- `ui/pg_canvas/canvas.py::_unify_subplot_bottom_axis_heights()` 将上层底轴设为 `setHeight(1.0)`。
- `_try_apply_subplot_selection_delta()` 复用旧 PlotItem / ViewBox，重新设置 bottom 角色和 xlabel。
- `overlay_axes.py::_configure_subplot_bottom_axis()` 恢复 `showValues`，但没有解除固定高度。
- `_unify_subplot_bottom_axis_heights()` 在底轴数小于 2 时返回，跳过最后一根轴的 `setHeight(None)`。
- `_subplot_realized_geometry_is_usable()` 只检查绘图区具有足够尺寸；绘图区过大侵占轴空间仍会通过。

## 3. 必须满足的行为合同

### C1：轴角色恢复完整且幂等

每次最终拓扑确定后，按当前角色完整投影轴状态，不能依赖上一种模式遗留值。

| 当前角色 | 刻度与标题 | 空间策略 |
|---|---|---|
| 分屏非最底行 | 不显示横轴数字和标题 | 保持既有约 1 logical px 的收起空间 |
| 分屏最底行，包括唯一行 | 按当前刻度／xlabel 意图显示 | 解除上层行的固定高度，按当前字体与内容预留 |
| 叠加共享 X 轴 | 由 X-master 对应底轴展示 | 一个可见横轴预留区；aux ViewBox 对齐主绘图区 |
| 隐藏／零活动行 | 不占活动行空间 | 不将旧轴高度、旧画面误认为当前可见状态 |

重复应用不累积宽高，不增加监听器或计时器，不改变 X/Y 数值范围。
保留原第一行、中间行、最后一行都必须正确；再次增加／恢复通道同样正确。

### C2：布局完成后才展示新画面

顺序合同：确定拓扑与身份 → 设置范围、轴角色、字体、刻度和标题 → 测量轴预留区 →
激活各 PlotItem 内部布局及外层布局 → 同步 overlay aux 几何 → 在最终几何上结算 → 展示。
实际实现应复用现有 owner 和收尾入口，不要求复制这条链为第二个渲染系统。

- 字体、标题和可见刻度的实际度量决定预留区；禁止把探针的 36.8 或其他经验像素写死。
- 同一字体／DPR／内容意图下，首帧不得通过挤压绘图区再补轴空间。
- 模式变化本身可以改变合理的布局；比较的是目标模式首帧和目标模式稳定帧，不要求两种模式相同。
- 不用 sleep、固定延时、反复全局 processEvents 或单纯 QTimer(0) 冒充布局完成屏障。
- 若有刻度文本宽度与图宽相互依赖，使用明确、有界的测量／布局步骤；不允许无限收敛循环。
  达不到边界合同须记录原因并保持该验收项未通过，不能强行宣布 ready。

### C3：只在证据需要时抑制中间展示

优先使现有同步路径在返回前完成几何准备。T0 证实用户可见半成品帧后，才选择：

1. 同步更新中的中间 paint：使用最小作用域的展示抑制，保留并在 finally 恢复原更新状态；
   不能依赖屏蔽更新本身来完成文本测量。
2. 必须跨事件循环才能完成的路径：才考虑短时保留上一幅已完成画面。
   不预先实施截图覆盖层或异步状态机。

若启用第 2 条，必须在实施记录明确所有者、内存上限、DPR、销毁与失败路径。
只能保留当前画布的一份既有完成帧，不得通过重算／强制 AA 抓图制造额外重绘。
旧画面期间不允许把拾取、游标、拖动作用于不同的新拓扑；成功后立即撤去，异常／关闭也清理。
快速连续切换须由现有渲染门禁协调，过期完成事件不得覆盖最新状态。
没有旧画面的首次绘制不能伪造旧数据，仍须满足首个新数据帧几何正确。

### C4：与现有结算和状态合同兼容

- 保持 `restore_visible_xlim(flush=False)` → `restore_visible_ylims()` → `settle_view_restore()`。
  将必要的布局完成放在该事务最终数据／质量结算之前，不新增一遍 envelope/ink 计算。
- 保留 150 ms 交互静止窗口、独立离散 settle timer、paint backstop 与现有 AA/ink 阈值。
  几何稳定不等于 AA 必须首帧开启；不以禁止 AA 或光栅回退来消除闪烁。
- 保留 composite source/channel identity、隐藏意图、游标、备注、共轴成员、颜色、图例、X/Y 范围。
- 正常勾选仍使用已有 subplot 对象复用；禁止为规避高度残留而每次全量重建。
- 若新增短暂状态，仅由现有 canvas owner 或明确 collaborator 持有，初始化、clear、异常和 teardown 对称。
  MainWindow 只编排，不新增跨 mixin 状态；复用 `TimeRenderGate`，不另建并行门禁。
- 本次不修改 `CLAUDE.md`；如实际实施需要改变共享架构守卫，先对照两份指令并单独说明。

## 4. 测量与验收标准

### 4.1 定义

“首帧”指目标画面实际交给可见 viewport 绘制的第一帧，不是调用返回、主动 flush 后截图或第一个 timer。
“稳定帧”指同一输入下目标布局完成且后续事件不再改变边界的帧。
若保留旧画面，旧帧期间单独计时，不能丢掉等待时长后宣称零延迟。

探针记录时间戳、操作／模式、复用／重建原因、活动行身份、轴角色、固定高度、
PlotItem 内外布局矩形、ViewBox 矩形、刻度实际绘制数量与文本框、标题框、DPR、paint 序号。
AxisItem.sceneBoundingRect() 可能包含网格延伸，不能将它直接当成轴预留高度；
高度取布局几何／height，文本用真实 draw specs 或绘制输出映射到同一坐标系。

### 4.2 Gates

| Gate | 通过标准 |
|---|---|
| G1 角色恢复 | 3→2→1、3→1、1→3，以及保留第一／中间／最后行均符合 C1；只剩一行的可见底轴不残留 1 px 固定高度 |
| G2 空间正确 | 可绘出的正常范围至少一个有效 X 数字；刻度／标题不进入绘图区、不被 viewport 裁掉；上层无额外横轴空带 |
| G3 首帧稳定 | 固定输入、尺寸和字体下，从目标首帧到稳定帧，绘图区边界漂移 ≤1 physical px；DPR 转换一次；无新增外部 resize 时不得二次明显收缩 |
| G4 模式切换 | 实际应用分屏↔叠加各方向至少 10 次，冷建与暖切均记录；无半成品轴、空白闪帧或旧新内容混合 |
| G5 兼容性 | X/Y 范围及 composite 身份保留；共轴双成员和逐曲线着色图例正常；游标／备注不失联；恢复只结算一次；交互 timer 不变 |
| G6 性能与生命周期 | 不增加全量重建、数据刷新或 ink 结算次数；无遗留冻结、覆盖层、计时器和 Qt wrapper；同机 A/B 报告切换返回与首个正确画面 p50/p95 |

G6 时间判定：使用同机同数据连续 A/B；至少 20 次暖切。
新增首个正确画面 p95 超过基线 `max(5 ms, 基线的 10%)` 时必须定位并减少额外工作，
或以实际消除的半成品帧成本解释取舍供评审；不得静默放宽已有交互性能标准。
这是本计划的回归预算，不是已测性能或普遍即时响应保证。

矩阵：普通 time-X、Custom-X；1/2/3/多行（含 24 行布局冒烟）；单组共轴、共轴加独立行；
短／长中文标签和混合单位；正常／窄窗口；DPR 1、2，Windows 可用时追加 125%/150%；
零选择恢复、隐藏后显示、快速连续切换、异常退出更新、跨屏字体／DPR 变化。
确定性自动化覆盖可组合维度，不要求整个矩阵笛卡尔积。

证据分层：offscreen 自动化、原生 Cocoa 探针、完整 TraceLab 前台、Windows 真机各自记状态。
缺失平台记 UNVERIFIED；合成数据通过不能声称客户文件已验收。
B 未捕获实际异常帧或未取得可信同路径验证时，不能写“闪烁已修复”。

# Documentation Map

Use `docs/analyzer/` for MF4 Data Analyzer product, UI, acquisition, and
review artifacts.

Keep these top-level folders separate:

- `docs/analyzer/` - analyzer-facing product docs, feature docs, UI prototypes,
  user guides, and review/report artifacts.
- `docs/superpowers/` - historical Superpowers specs/plans/reports that are
  part of prior implementation workflow records.
- `docs/lessons-learned/` - repo-local Codex lessons system only.

New analyzer feature plans, feasibility notes, runbooks, and reviews should go
under `docs/analyzer/` unless a task explicitly needs the historical
`docs/superpowers/` workflow archive.

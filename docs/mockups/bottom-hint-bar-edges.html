左侧旋转手势提示靠左缘，右侧"发现"提示靠右缘，中间留空。

现状（两条都堆在中间，一组居中）
— chart canvas —
Ctrl / Shift + 滚轮 缩放 X / Y · 顶部按钮支持快捷键，悬停按钮即可查看
两条挤在中间；左侧文字一长就被居中挤压、提早省略，左缘大片空白浪费。
方案：左右靠边（常规长度）

Ctrl / Shift + 滚轮 缩放 X / Y 顶部按钮支持快捷键，悬停按钮即可查看

方案：左侧文字很长时（先省略，绝不挤掉右条）

左条占满到右条左缘后以"…"省略；右条始终完整可见、不被推走。
方案：右条已"退役"/为空时（只剩左条）
